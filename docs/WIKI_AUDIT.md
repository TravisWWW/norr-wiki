# Norroth Wiki 结构与内容评估

评估日期：2026-10-14。线上地址：https://traviswww.github.io/norr-wiki/ 。源码与远程基线：`b626ace528d400b0c90e4c2046a89b3ba0cb4afb`，评估时 `git ls-remote origin HEAD` 与本地 HEAD 一致；已实际打开线上首页核对栏目与入口。

## 总体判断

站点已经具备较完整的机制百科和数据查询基础。主要短板是读者进入路径、攻略覆盖和数据适用性解释，而不是缺少一级分类。优化保留十个主题与现有文章地址，补齐栏目总览与行动路线，让已有资料更容易被发现和串联。

| 维度 | 基线评估 | 已完成调整 |
|---|---|---|
| 组织结构 | 已有十个主题，但多数首页分类直接落到一篇正文，例如“任务与挑战”进入副本页、“养成与社交”进入宠物页 | 增加八个栏目总览，职业与生活技能复用现有总览；首页、侧栏、目录共用导航定义 |
| 内容分区 | 新手与五篇版本资料同层；三篇攻略、工具和编辑资料混排 | 新手 / 版本，任务 / 挑战 / 活动，攻略 / 工具 / 参考分别组织；默认收起无关主题 |
| 内容丰富程度 | 63 个内容页面；机制、职业与图鉴覆盖较广，攻略只有 3 篇 | 新增练级、日常、装备三篇攻略与 FAQ；总计 76 个内容页面，含八个新目录和一个覆盖页 |
| 内容可信度 | 已有 EA / 1.0 标记和来源说明，但收录规模与缺口难以整体判断 | 从实际页面生成全站目录、状态和核对日期；汇编攻略显示性质，不新增实测日期 |
| 读者体验 | 首页主要提供分类浏览，缺少按目标选入口；常用工具只展示两个 | 增加四个目标入口和四个查询入口；手机目录单列，表格可横向滚动，保留搜索 |
| 维护成本 | 首页分类与配置中的导航重复维护 | 统一为 `src/navigation.mjs`；补构建后站点检查，并接入部署流程 |

## 内容规模与范围

- 优化前 63 个内容页面，优化后 76 个；新目录不等于新机制数据。
- 已收录 730 条装备记录、1216 条制作配方、141 条怪物记录、15 个副本记录和六职业技能资料。数字来自现有数据文件，未进行新增游戏抓取。
- 装备与配方图鉴有筛选和材料相关查询，是站点已有优势；不能由记录数量推定覆盖全部掉落、随机词条或 1.0 内容。
- 新手指南和日常任务已有操作步骤，但缺少将规则串成完整行动顺序的页面；新攻略主要补这一层。
- 新攻略主要依据站内 EA 资料整理，保留原规则链接；没有补造掉落率、市场收益、全等级练级效率或正式服实测结果。

## 具体变更

1. 首页按“目标 → 主题 → 图鉴工具 → 版本资料”排列。版本计划时间集中在发布页，避免首页长期保留静态“待上线”状态。
2. 增加入门、战斗、装备、世界、任务、养成社交、经济与攻略八个栏目总览。既有 `classes/` 和 `professions/overview/` 作为对应主题总览。
3. 新增新手 FAQ、EA 新手练级与探索、日常安排与预算、装备养成与更换决策。
4. 新增内容覆盖页，列出全站入口、资料状态、已有核对日期与内容缺口。栏目交叉引用明确说明，不把重复入口计作新增文章。
5. 修正日常档位奖励的算术合计：`5+5+20+40=70` Laurels、`100+100+250+500=950` Coins、`100+100+250+1000=1450` Spirit Essence。区分档位奖励、单条奖励与净收益。
6. 页面标题显示已有 `reviewStatus` 字段，并将 Date 类型的核对日期格式化为 `YYYY-MM-DD`。日期格式化不构成新的规则验证。
7. 添加 `npm run check:site`，检查构建中的内容路由、导航、内部链接、锚点和静态资源；GitHub Actions 在上传 Pages 产物前运行。

## 验证

- `npm run build` 成功：76 个内容页面、一个 Starlight 404 路由，以及公开模拟器静态 HTML。
- 首轮站点检查对照基线 Git 树，确认原有 63 个内容路由全部存在；新增目录没有移动原文章。
- 最终 `npm run check:site` 覆盖全部 HTML、十个栏目入口与 76 个内容路由；具体链接计数以脚本输出为准。
- 桌面首页：十个分类卡片，页面 / 装备 / 配方统计正确；无缺失图片或页面水平溢出，已检查截图。
- 390px 手机：首页、新手路线、覆盖页、装备与配方图鉴均无页面水平溢出；覆盖页十个状态表格可独立滚动，已检查截图。
- 搜索“日常安排”能找到新增日常攻略和关联入口。
- 装备搜索 `Cotton` 从 730 件筛至 25 件，展开 `Cotton Wrap` 显示属性和材料。
- 配方链接 `?prof=armorsmithing` 自动筛选至 130 条配方。
- `git diff --check` 通过。

构建保留了既有的字体 / 首页背景路径延迟解析提示和空 i18n / 404 内容提示；资源实际存在，链接检查与浏览器加载正常。这些提示不表示上述游戏规则已经实测。
