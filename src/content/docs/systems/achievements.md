## 结论速览

- **AP（Achievement Points）** 是**累积成就点数**，由做成就累积；**与可消费的成就代币余额不同**。
- **Achievement Tokens** 是**可消费货币**，用于 Achievement Market。
- 官方一次性列出**全部成就**的名称 / 描述 / Token 奖励。
- **1.0 奖励页**记录正式服兑换信息（见下）。

## AP 与成就代币

- **AP = Σ(已达成成就的 Token) + 任务给的 AP**，是**累积值**。
- 钱包里的 **Achievement Token 是「可消费余额」**，用完不影响 AP，两者不应混淆。
- 成就等级（Achievement Lvl）按 AP 分档，**档位越高解锁越多** Achievement Market 商品。

> 版本说明：AP 的结算时机与档位阈值可能随版本调整，**1.0 上线后需重新核对**。

## 成就清单

- 官方帮助文档一次性列出全部成就的名称 / 描述 / Token 奖励（静态页，不含个人进度）。
- 游戏内的成就进度可在**职业弹窗**下半部分查看（每条显示名称 / 描述 / 是否达成）。
- 成就覆盖：探索地图、职业等级、击杀数、游戏时长、旅行距离、金币、城市发现、
  击杀 Boss、属性、阵营、角色等级、仓库 / 背包格数、竞技场分区、活动、副本等。

## 1.0 Launch Rewards

- 入口：菜单 → **1.0 Rewards**。
- 页面给出 **unique code**，**1.0 正式服兑换用，只能兑一次**。
- 页面有两套分：
  - **Achievement Points (AP)** —— 由「做成就」累积。
  - **Norroth Coin Points (NC)** —— 只有充值才有。

> **安全提示**：兑换码属于个人凭据，请勿公开或分享；本站不展示任何真实兑换码。
