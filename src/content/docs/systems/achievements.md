## 结论速览

- **AP（Achievement Points）** 是**累积成就点数**，由做成就累积；**与可消费的成就代币余额不同**。
- **Achievement Tokens** 是**可消费货币**，用于 Achievement Market。
- 官方一次性列出**全部成就**的名称 / 描述 / Token 奖励。

## AP 与成就代币

- **AP = Σ(已达成成就的 Token) + 任务给的 AP**，是**累积值**。
- 钱包里的 **Achievement Token 是「可消费余额」**，用完不影响 AP，两者不应混淆。
- 成就等级（Achievement Lvl）按 AP 分档，**档位越高解锁越多** Achievement Market 商品。

## 成就规模【1.0 官方 Wiki】

官方 1.0 Wiki 的 **Achievements** 页一次性列出 **526** 个成就（名称 / 描述 / Achievement Token 奖励），代币合计 **91,940**，覆盖深渊塔、Boss、探索、职业、竞技场、活动、属性、等级、旅行距离、金币、阵营、重生等。完整清单见官方页 <https://wiki.norroth.com/p/54/achievements>。

## 成就覆盖范围（示例）

- **深渊之塔**：Normal / Nightmare / Chaos 各层数里程碑。
- **Boss / 击杀**：累计击杀 Boss 与敌人数量。
- **探索**：发现城市、探索地图数量、旅行里程。
- **职业与专业**：各职业等级、各专业等级（含 **Paragon** 里程碑）。
- **属性**：Agility / Power / Spirit / Toughness / Wisdom / Luck 等阈值。
- **阵营**：Dark / Light Alignment 阈值。
- **重生**：Rebirth Level 1–10。
- **其它**：游戏时长、金币持有、任务完成数、推荐好友等。
