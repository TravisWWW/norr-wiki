## Achievement Market（成就商店）

- 货币：**Achievement Tokens**。
- 面板顶部显示 **Achievement Lvl: Tier N** —— 成就等级解锁更高档商品。
- **价格固定，不随数量变化**。

| 商品 | 价格（Achievement Tokens） |
|---|---|
| **Inventory Slot Expander** | **50** |
| **Stash Slot Expander** | **150** |
| Gold Aureus (1) | 100 |
| Prevent Exp Loss Charm | 200 |
| Teleportation Scroll | 40 |
| Item Repair Kit | 40 |
| Small Increase Experience Charm | 150 |
| Small Increase Coins Charm | 100 |
| Copper Key | 20 |
| Iron Key | 40（Tier 2） |
| Stats Reset Tablet | 400 |
| Skills Reset Tablet | 400 |

- **Inventory Slot Expander / Stash Slot Expander 每个 +1 格**。
- 扩容道具买到后立刻使用。

## Laurel Market（Laurel 商店）

- 货币：**Golden Laurels**（日常任务 / 成就奖励）。
- 卖首饰盒、钥匙、护身符、宝石 / 稀有度代币、骰子、镶嵌锤等（详见配套商店）。

> 任务板与任务奖励见[任务板与日志](/norr-wiki/quests/boards/)。

> NPC 商店的**动态库存**说明见[商人与药水](/norr-wiki/equipment/vendors/)。

## 代币商店与氪金档位【1.0 官方 Wiki】

- **Achievement Market**：用**成就点数**购买，成就等级每升一档解锁更多商品。
- **Norroth Coins Shop（金币商店）**：用真钱购买 **Norroth Coins (NC)**，用于皮肤 / 光环 / 特效等高级购买；**每 1 NC = 10 Prestige Points**。
- **Celestial Tier Spender（星界档位消费奖励）**：购买 NC 时按 **Prestige Points** 累积，共 **10 档 × 4 检查点**，每个检查点解锁可领取奖励（含个人与社区 / 服务器奖励）；部分特殊礼包不计入。
- **Laurel Market**：用 **Golden Laurels** 兑换，**成就 Tier 越高解锁越多**；Laurels 来自 Client Order Board、Overlord、每周 Legend Box、Daily Tasks。
