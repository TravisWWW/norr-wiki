## 成就奖励都在邮箱里，必须手动领取

- 邮件是成就奖励的入口，**不点 Collect 就永远拿不到**。
- 收件箱有上限，满了会提示；**已满时仍能逐封打开并 Collect**，领完会自动腾出位置（要**多轮领取**）。
- 邮件类型：`Achievement!`、`Level N reached!`、`Welcome to Norroth`。

## Achievement Market（成就商店）

- 货币：**Achievement Tokens**。
- 面板顶部显示 **Achievement Lvl: Tier N** —— 成就等级解锁更高档商品。
- **价格固定，不随数量变化**。

| 商品 | 价格（Achievement Tokens） |
|---|---|
| **Inventory Slot Expander** | **50** |
| **Stash Slot Expander** | **150** |
| Gold Aureus (1) | 100 |
| Prevent Exp Loss Charm | 200 |
| Teleportation Scroll | 40 |
| Item Repair Kit | 40 |
| Small Increase Experience Charm | 150 |
| Small Increase Coins Charm | 100 |
| Copper Key | 20 |
| Iron Key | 40（Tier 2） |
| Stats Reset Tablet | 400 |
| Skills Reset Tablet | 400 |

- **Inventory Slot Expander / Stash Slot Expander 每个 +1 格**。
- 扩容道具买到后立刻使用。

## Laurel Market（Laurel 商店）

- 货币：**Golden Laurels**（日常任务 / 成就奖励）。
- 卖首饰盒、钥匙、护身符、宝石 / 稀有度代币、骰子、镶嵌锤等（详见配套商店）。

## 任务

- 任务板分 **Client Order Board** 与 **Bounty Hunter Board**（另有公会专属任务板）。
- **完成任务用「finish」**，奖励进掉落窗，需领取。
- 任务样例：交材料 → 钥匙 + 生活技能经验 + 战斗经验 + 金币。
- 材料来源：Slate 在 Stonemason、Mucky Vegetables 在 Cook 等，约 4 币/个。
  → **Order 任务可通过「购买材料 → 交任务」换取金币 / 钥匙 / 经验**，收益较高。
- 详见[任务板与日志](/norr-wiki/quests/boards/)。

## 商店库存是动态的

> **说明**：NPC 商店的**库存数量随机、约每 2 小时刷新一次、且有限额**，可能被其他玩家买空。
> 但**档次是固定的**：**1 级城市只卖 T1 材料**，10 级城市（Elundi）卖 T2 档。
>
> 记录的「库存数字」仅为某一时刻的快照，**不代表固定值**；价格相对稳定，库存不稳定。
