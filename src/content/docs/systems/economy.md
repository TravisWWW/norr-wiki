## 结论速览

- 货币：金 / 银 / 铜（Coins），另有 **Spirit Essence、Golden Laurels、Achievement Tokens、Ducats、Rebirth Marks、Shadow Coins、Norroth Coins** 等特殊货币。
- 收入来源：打怪、卖店、玩家市场（Trading Post）、代币商店、Celestial Market。
- **Trading Post** 是玩家间买卖的主渠道，分 **Equipment / Materials** 两栏。

## 货币体系

| 货币 | 来源 | 用途 |
|---|---|---|
| **Coins**（Bronze / Silver / Gold） | 打怪掉落、卖店、任务、日常 | 商人买卖、洗属性、修装备、开公会 |
| **Spirit Essence** | 战斗掉落、Geodes、日常、灌注石兑换 | **Waygate 传送**、宠物、部分配方 |
| **Golden Laurels** | Client Order Board、Overlord、每周 Legend Box、Daily Tasks | Laurel Market |
| **Achievement Tokens** | 完成成就 | Achievement Market |
| **Norroth Coins (NC)** | 真钱购买 | Celestial Market（QoL / 皮肤 / 礼包） |
| **Event Tickets** | 活动积分 | Event Merchant |
| **Ducats** | Overlord、日常、远征 | 船只升级 |
| **Rebirth Marks** | 每次成功重生 | Eldritch Caretaker（账号共享） |
| **Shadow Coins** | 主线任务、副本、副本战利品箱、部分日常 | Shadow Broker |
| **Chaos Crests** | Abyssal Tower 通关 | Abyssal Merchant |

**币值换算**：**1 Gold = 100 Silver = 10000 Bronze**。

> **命名说明**：游戏内货币统一为 **Coins**（Bronze / Silver / Gold 三级），文中「金币」泛指 Coins，**不是**独立货币；真钱货币是 **Norroth Coins**（氪金），两者勿混淆。

## 交易行 Trading Post【1.0 官方 Wiki】

- 分 **Equipment Post**（装备、宝石、宠物、工具）与 **Materials Post**（原材料、制作材料、消耗品）。
- **手续费**：挂买单 / 卖单收**买卖价的 2.5%**；当买卖价**超过商店价 10 倍**时收 **10%**。
- **价格标签**（基于商店价，帮判断材料贵贱）：
  - **买材料**：`A` 划算（< 2x 商店价）、`E` 贵（> 10x）、`F` 天价（> 20x）；无标签 = 市场价。
  - **卖材料**：`F` 亏（≤ 商店价）、`B` 尚可（10x–20x 商店价）、`A` 极佳（> 20x 商店价）。
- **Post Order**：设自定义数量与价格的买单；**金币会被冻结**直到卖家成交或你取消。

## 各市场【1.0 官方 Wiki】

| 市场 | 说明 |
|---|---|
| **Laurel Market** | 用 Golden Laurels；**成就 Tier 越高解锁越多商品** |
| **Achievement Market** | 用 Achievement Tokens；每升一个 Tier 加新商品 |
| **Celestial Market** | 氪金市场（Norroth Coins）：QoL 道具、皮肤、光环、Value Packs |
| **Event Merchant** | 用 Event Tickets；在 Event Gate 左侧 |
| **Shadow Broker** | 用 **Shadow Coins** 向 Nari N'Deyala 购买**随机装备**（自选部位，物品 / 稀有度 / 品质未知）；物品按**当前地图等级**缩放，高级区域更贵更强 |
| **Eldritch Caretaker** | 用 **Rebirth Marks** 兑换重生专属商品；**Rebirth Level 0–10** 决定解锁项 |

## 灌注石 Infusion Stones【1.0 官方 Wiki】

- 存在 **Currency Pouch** 中，从 **Infusions** 菜单打开。
- **传送充能**：每颗灌注石 +**200 Teleport Charges**（上限 **9,999**）；地图传送每移动 1 格消耗 **1** 充能；地下城 / 远征 / 深渊之塔内**禁用传送**。
- **兑换灵气精华**：每颗灌注石 = **5,000 Spirit Essence**。
- **战斗复活**：9 级及以上（非 Hardcore）战斗失败后可花 **1 颗**原地复活，恢复**半血 + 满蓝**，随后进入复活冷却。
- **大师制作**：6–10 级每步 1 颗、11–15 级每步 2 颗、16–20 级每步 3 颗。
- **房屋 / 公会升级**：部分房间升级各需 1 颗；公会银行 **Stack Size** 升级需 **20 颗** + Guild Tokens + 金币。
- **来源**：精英 / 稀有 / 冠军 / Boss 必掉特殊掉落、普通怪小概率、随机礼物；副本战利品箱（铜 / 铁 / 青铜 1 颗，钢 / 秘银 2 颗）；登录第 10 天；特殊订单；成就里程碑；Celestial Market；Trading Post。

## 传奇 / 遗物代币【1.0 官方 Wiki】

- **Legendary Upgrade Token**：把 **Ascended** 物品升为 **Legendary**。
- **Relic Upgrade Token**：把 **Legendary** 物品升为 **Relic**。
- **来源**：Overlord、对应远征（Legendary / Relic）、Strongboxes、商人（**10 个碎片**换 1 个完整代币；碎片在 Arena Merchant 购买）。
- **升级方式**：**Ember Forge** 100% 成功（需 Emberdust + Spirit Essence）；或 **Item Specialist** 从 25% 起，每次失败 **+5%** 直到 100%，**每次尝试都消耗代币**。

## 战利品强化 Trophy Enhancing【1.0 官方 Wiki】

- 在猎人 **Artemas Fletcher** 处用精炼的**战利品材料**给装备绑定一条**随机属性**。
- 每件装备**同时只能有一条** Trophy Enhancement；再次强化会**替换**旧加成。任意角色可用，**不需要 Hunting 专业**。
- **材料类别需匹配物品类型**：武器（Offense）、防御副手 / 护甲（Defense / Utility）、攻击副手（Offense）、珠宝（全部）。
- **费用**：匹配品质材料 **1 × 物品 Tier**（如 T5 物品需 5 个 Quality 级材料）+ 金币 **物品等级 × Tier × 5**。
- **结果**：从材料池随机取一条属性，强度在 **0.80×–1.20×** 之间；恰好 **1.20×** 标记为 **☆PERFECT☆**；物品名会更新为绑定战利品的名称。

## 拆分堆叠 Split Stack【1.0 官方 Wiki】

右键数量 > 1 的材料堆叠 → 选 **Split Stack** → 选择新堆叠数量 → 点 **Split**。
