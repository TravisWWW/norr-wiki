> **资料状态**：官方已明确**玩家可以拥有住房**，且开发日志已披露**部分功能方向**；
> 但获取方式、建造材料与最终规则仍**待 1.0 上线核实**。

## 已确认内容（官方）

- 官方商店页明确列出**玩家住房（Player Housing）**为正式版内容之一。
- 住房属于官方公布的正式版新增系统，与 EA 版现有系统可能不同。

## 开发日志已披露的功能【官方 · 1.0 测试期口径】

> 以下来自官方开发日志，**属于已披露的规划 / 测试期功能**，不代表正式服最终实现。

- **Personal Estates（个人庄园）**：提供**大量额外存储**。
- **从银行直接制作 / 强化 / 精炼 / 升级**：制作、Trophy Enhancing、Refining、Ship / House / Guild 升级窗口均可直接从银行取料，省去来回搬运（见[大师制作](/norr-wiki/professions/masterworking/)）。
- **可从个人庄园直接访问的设施**：**Dock / Charter Box**、**Jewelry Box** 等。
- 原 **Stash 更名为 Bank**，并**大幅扩容**。

## 住房设施【1.0 官方 Wiki】

**Personal Estate（个人庄园）**：花 **10 金币**买地、命名，之后可从城镇随时进入，作为个人成长与功能区域。
**Estate Planning（地基）**：升级地基可扩大场地、提高所有房间 / 设施 / 升级的**等级上限**；庄园初始为 **T1**。

| 设施 | 作用 | 容量（每 Tier） |
|---|---|---|
| Bedroom 卧室 | 睡眠完全恢复生命与法力、移除减益，并获得与该 Tier 匹配的随机增益 | — |
| Jewelry Box 珠宝盒 | 存放戒指 / 项链 / 耳环等珠宝 | 3 格 |
| Wardrobe 衣柜 | 存放护甲 / 头盔 / 护腿 / 手套 / 靴子 | 1 套 |
| Weapon Rack 武器架 | 存放武器 / 副手 / 工具 | 3 格 |
| Charter Chest 海图箱 | 存放远征地图 | 3 格 |
| Pet Shelter 宠物舍 | 存放宠物；被安置的宠物在庄园内游荡并缓慢回能 | 1 只 |
| Allotment 菜园 | 个人采集：种植 / 钓鱼 / 采集类碎料 | — |
| Nature Reserve 自然保护区 | 个人采集：采矿 / 采石 / 伐木类碎料 | — |

- 各房间 Tier 上限由 **Estate Tier** 决定。
- **Allotment / Nature Reserve** 需先建造至少一个子升级（Farming Field / Fishing Lake / Foraging Field；Mining Cave / Quarry / Grove）才会出现碎料，碎料 Tier 与对应子升级 Tier 一致。
- **Deposit Resources**：升级公会 / 住房 / 船只时可从背包与银行捐赠材料。
