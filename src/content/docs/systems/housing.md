## Personal Estate（个人庄园）

- **购买**：花 **10 金币**购买个人地块，并为庄园取一个**唯一名称**（最多 **15 字符**）。
- **进入**：购买后可从**城镇（Town）**随时进入；庄园是个人成长与功能区域。
- **等级门槛**：庄园在**角色 10 级**开放，从城镇 **Activities** 菜单的 **Personal Estate** 选项购买。
- **访客**：好友与公会成员可访问你的庄园（取决于你设置的权限）；**只有庄园主**能建造 / 升级。

## Estate Planning（地基 / Estate Tier）

**Estate Planning** 用于升级庄园**地基**——决定整块地产的承重结构：

- 每个庄园购买时从 **Tier 1** 开始。
- **Estate Tier 决定庄园内所有房间 / 设施 / 升级的最高 Tier**。
- 升级会**扩大场地**、**解锁更多建筑空间**；升级完成后庄园内所有人会被自动移动到新入口。
- 每级升级需要一定数量的 **Blueprints、Coins、Lucky Charms、Wood Planks、Stone Bricks**，且**材料 Tier 需与目标 Tier 匹配**。
- 用 **Deposit Materials** 从背包 / 银行贡献材料；材料永久保存，可分多次贡献，达标后点绿色 **Upgrade**。

### Noble Status 要求

- **Tier 2 以上**的所有庄园升级都需要 **Noble Status**。
- **进入任何 Tier 3+ 的庄园**（包括好友 / 公会成员的）也需要 **Noble Status**。
- **Tier 1 / Tier 2** 的升级与进入**不需要** Noble Status。

## 各功能房间【1.0 官方 Wiki】

| 设施 | 作用 | 容量（每 Tier） |
|---|---|---|
| **Bedroom 卧室** | 睡觉时**完全恢复生命与法力、移除减益**，并获得与该 Tier 匹配的**随机增益** | — |
| **Jewelry Box 珠宝盒** | 存放戒指 / 项链 / 耳环等珠宝 | **3 格** |
| **Wardrobe 衣柜** | 存放护甲 / 头盔 / 护腿 / 手套 / 靴子 | **1 套** |
| **Weapon Rack 武器架** | 存放武器 / 副手 / 工具 | **3 格** |
| **Charter Chest 海图箱** | 存放远征地图 | **3 格** |
| **Pet Shelter 宠物舍** | 存放宠物；被安置的宠物在庄园内游荡并**缓慢回能** | **1 只** |
| **Allotment 菜园** | 个人采集：种植 / 钓鱼 / 采集类碎料 | 随 Tier 提升 |
| **Nature Reserve 自然保护区** | 个人采集：采矿 / 采石 / 伐木类碎料 | 随 Tier 提升 |

- 各房间 Tier 上限由 **Estate Tier** 决定；用 **Place / Take** 存取，切到 **Upgrade** 标签升 Tier。
- **Allotment / Nature Reserve** 需先建造至少一个**子升级**才会出现碎料：
  - Allotment：Farming Field（种植）/ Fishing Lake（钓鱼）/ Foraging Field（采集）。
  - Nature Reserve：Mining Cave（采矿）/ Quarry（采石）/ Grove（伐木）。
  - 碎料的 **Tier 与对应子升级 Tier 一致**。
- **刷新**：进入自己庄园时，碎料每 **6 小时**刷新一次；数量 = 对应设施的 Tier，类型从已解锁子升级中随机；采完要等下次刷新。
- **Deposit Resources**：升级公会 / 住房 / 船只时可从背包与银行捐赠材料。
