> **适用版本**：以下为 **EA 版**行为；1.0 正式版可能调整邮件容量、附件与邮费规则。

邮件是玩家之间转移物品的主要方式（游戏内没有直接交易 / 赠送功能）。界面下方的 **Mailbox 按钮**随时能打开邮局，
**任何地图都能收发**，不必跑到邮箱格子。成就奖励都在邮件里，需要**手动点 Collect 领取**，否则不会进背包。

## 收邮件（领别人寄来的东西 / 成就奖励）

1. 打开邮局（界面下方 Mailbox 按钮，任何地图都可用）。
2. 收件箱列出所有邮件。
3. 打开某一封，正文里有奖励图标 + **Collect 按钮**。
4. 点 Collect 领取，奖励进背包 / 掉落窗。
5. 收件箱有上限，满了会提示 postbox is full；**已满时仍能逐封打开并 Collect**，
   领完会自动腾出位置、后面的邮件才显示出来（需要**多轮领取**）。

> 邮件类型：`Achievement!`、`Level N reached!`、`Welcome to Norroth` 等。

## 寄邮件（把材料 / 装备寄给别的玩家）

1. 打开邮局 → 写信（任何地图都能寄）。
2. 填三个文本框：**收件人角色名**、标题、正文。
3. 勾选要寄的东西：资源（可指定数量）或装备。
4. 提交。
5. **邮费** = `Σ ceil(资源单价 × 数量 × 0.1)` 金币。例：Slate 单价 1 币 → 寄 256 个收 26 币。

> 寄送数量按界面输入框填写即可；游戏内帮助文档未说明单封上限，实际以界面能提交的为准。

## 邮费

- **公式**：`Σ ceil(资源单价 × 数量 × 0.1)` 金币（装备按各自单价计入）。
- 例：Slate 单价 1 币 → 寄 256 个收 **26 币**（256 × 0.1 = 25.6，向上取整）。
- 邮费按**每类物品分别向上取整**后相加，因此拆成多封寄送通常更贵。

## 邮箱验证

- **账号邮箱未验证 → 不能发邮件、不能挂卖单**（交易站卖单同一门槛）。
- 验证方式：在账号设置里重发验证邮件，再到邮箱点验证链接 / 提交验证码。
- 验证码会超时，超时后重新发送即可。
- **买（Trading Post 购买）不受影响**，只有卖 / 挂单被挡。
