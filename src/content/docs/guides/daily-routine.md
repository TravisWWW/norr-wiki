日常不是必须清空的任务列表。EA 已收录规则为每条 10 点、30 / 60 / 90 / 120 点四档奖励；按当天面板选择任务。以下是安排建议，具体奖励和开放条件以正在玩的服务器为准。

## 先看面板，再规划目标

1. 打开 Activities → Dailies，确认今天哪些任务可完成。
2. 以面板服务器重置倒计时为准，避免把本地日期当作任务日。
3. 按可用时间选择一个奖励档位。EA 分别需要 3 / 6 / 9 / 12 条任务，不必为了满档执行当前无法承担的项目。
4. 检查金币、材料、工具耐久和副本钥匙，把已有条件纳入路线。

## 按机会成本排序

| 优先级 | 候选任务 | 先检查什么 |
|---|---|---|
| 顺手完成 | 免费礼物、接任务板任务、修理、卖材料 | 今天任务池是否包含；是否已经需要这项操作 |
| 与练级合并 | 击杀、采集、拾取野外杂物 | 当前地图与工具是否合适 |
| 与制作合并 | 制作材料或装备、拆解闲置装备 | 是否确实需要成品，材料和设施是否已具备 |
| 有预算再选 | 交易站购买、许愿井、精炼 | 实际报价、金币和风险；精炼需成功才完成 |
| 有资格再选 | 副本、竞技场、喂宠、公会捐献 | 钥匙、等级、宠物或公会条件是否满足 |

不必为了日常专门付费购买，也不必为了一个档位强行升级稀有度。任务点数相同，成本和收益不同。

## 一条可调整的日常顺序

**城内整理 → 顺路野外战斗 / 采集 → 回城制作与交易 → 领取奖励。**

- 城内先处理礼物、任务、修理和闲置资源。
- 出城时把击杀与采集合并到正在进行的主线或练级路线。
- 回城后只制作所需物品；当天缺几条任务时，再比较交易、许愿、精炼或进本的成本。
- 最后核对任务完成状态，领取每个已达成的档位和单条奖励。

这里不承诺固定完成时间：任务池、角色能力、地图和设施距离都会改变耗时。

## 收入怎么计算？

EA 日常页已收录四个档位合计约 **70 Laurels、950 Coins、1450 Spirit Essence**，另有随机奖励、2 个 Battle Arena Token 和 2 个 Ducats。它们是四档奖励的合计，**不是当天净收益**。

当天净收益还需加上单条任务奖励，扣掉购买、精炼、许愿等支出；材料与钥匙消耗单独记录。随机奖励不能按保证掉落的具体物品计入预算。

## 资源留给哪些用途？

- **Coins**：结合修理、商人补给、鉴定与强化报价安排预算。
- **Spirit Essence**：传送与其他用途见[经济与货币](/norr-wiki/systems/economy/)。准备探索前先查传送费用。
- **各类代币**：先看[代币商店](/norr-wiki/systems/token-shops/)，不同代币不能视为等价资源。
