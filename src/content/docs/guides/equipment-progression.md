装备养成先解决可用性与当前战斗短板，再考虑追加投入。以下顺序主要依据 EA 已收录机制整理；没有跨职业的收益测试，不能直接当作所有角色的最优配装。

## 第一步：确认装备能用

- 先鉴定未知 Quality 和隐藏词条，再比较真实属性。
- 确认职业、等级和武器类型；盾系技能需满足实际装备条件。
- 核对耐久与槽位。Tome 占副手 / shield 槽，不能把两个副手收益同时计入。
- 从[装备图鉴](/norr-wiki/equipment/catalog/)查已收录的基础属性和材料，随机词条仍以手上物品为准。

## 第二步：按战斗表现找短板

| 现象 | 先检查 | 再考虑什么 |
|---|---|---|
| 经常未命中 | Hit Rating、目标等级与技能条件 | 相关属性或词条；不要只追加 Damage |
| 普通物理攻击伤害过高 | 耐久、防御与当前护甲 | 更合适的防御属性与装备 |
| 法术伤害难以承受 | 抗性与目标伤害类型 | 对应防护，具体计算查属性页 |
| 蓝量不足 | 技能耗蓝、实际施放频率与续航 | 技能配置、法力恢复和补给 |
| 能稳定存活但战斗较慢 | 命中、技能栏与有效伤害 | 比较武器或输出词条收益 |

## 第三步：比较换装备与强化

| 决策 | 适合考虑的情况 | 主要成本 |
|---|---|---|
| 更换装备 | 等级提升后有明显更合适的基础装备 | 掉落、购买或制作成本；鉴定费用 |
| 精炼 | 预计持续使用，基础类型和词条已合适 | 金币、成功率及面板碎裂风险 |
| 开孔与镶嵌 | 已确定装备值得长期投入 | 开孔、宝石与辅助材料；提取也有成本 |
| 重铸或升稀有度 | 核心装备短板明确，能承受不确定收益 | 金币、材料、成功率与失败后果 |

建议先检查能否用较低成本更换装备解决问题，再对留用装备追加投入。材料和金币有限时，先满足主力装备与补给需求。

## 强化前检查清单

1. 在 Item Specialist 面板核对本次金币与材料费用。
2. 分别读取成功率与碎裂率；**没有提升**与**装备损毁**是不同结果。
3. 已收录资料对碎裂风险出现于 Q31 / Q32 的描述存在口径差异，实际操作以面板为准，不能只依赖攻略阈值。
4. 镶嵌前确认已有孔位；取回宝石时核对 Extractor 的保留概率。
5. 别把所有资源投入即将替换的装备；保留足够修理和探索补给。

## 职业配装与资料缺口

目前有[狂热者配装攻略](/norr-wiki/guides/zealot-build/)，其余五职业以职业页的定位与技能说明为主。尚缺完整的多阶段装备清单、跨词条收益测试与 1.0 成品实测；不能把 Zealot 的加点优先级通用于其他职业。
