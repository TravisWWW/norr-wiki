这条路线把官方 1.0 规则整理成上手顺序。地图选择是建议；尚无覆盖六职业、全等级的统一效率测试，不能据此认定为最快练级方案。

## 出城前准备

1. 在[职业总览](/norr-wiki/classes/)比较战斗定位和制作专业，再阅读所选职业的技能说明。
2. 检查武器、职业限制和装备耐久。掉落装备先鉴定再比较，避免把隐藏属性当作零收益。
3. 阅读[技能系统](/norr-wiki/combat/skills/)，确认技能已经加入实际使用的技能栏。
4. 打开任务日志，确认正在推进的主线。主线任务与任务板是两套入口。

## 核心口诀（官方新手指南）

- **每级花完 5 点属性 + 1 点技能**。
- **跟着任务走**：紫 = 主线（优先）、橙 = 支线、蓝 = 日常、绿 = 可交付。
- **打同级怪**（绿 / 黄），避开橙 / 红；灰名怪几乎不给经验。
- **按阶梯换装**：1-9 = 1 阶、10-19 = 2 阶、20-29 = 3 阶……持续提升品质与等级，但别在低级物品上重投。

## 每次战斗之后

- **先拾取尸体**：战斗经验在拾取时结算；只击杀不领取会漏掉经验。
- 如需拾荒材料，再在尸体仍存在时使用 Scavenging；战斗经验与拾荒经验分开计算。
- 看实际命中、战斗回合数和生命 / 法力消耗。单只怪的经验更高，不一定使单位时间收益更高。
- 回城时交任务并领取掉落窗中的奖励，再修理装备和补充消耗品。

## 什么时候换图？

| 当前表现 | 建议 |
|---|---|
| 怪物灰名、没有战斗经验 | 先排除未拾取，再寻找等级更合适的地图 |
| 能稳定完成战斗，移动时间也少 | 可以继续；升级后重新检查怪物颜色和经验 |
| 经常打空、战斗拖长 | 查命中与技能配置，再决定是否降低目标等级 |
| 死亡频繁、补给消耗过高 | 检查耐久、防御与抗性，回到可持续战斗的区域 |

## Lv10 之后如何继续

可按[地图清单](/norr-wiki/world/maps/)筛选适合的区域，再结合[怪物图鉴](/norr-wiki/world/bestiary/)查目标。需要物品专家服务时，可查询城镇设施；传送是否可用取决于已发现地图和 Spirit Essence（见[传送](/norr-wiki/world/movement/)）。

每次更换练级区记录一小段实际游玩中的经验增量、耗时、死亡和补给消耗，再比较收益。不要只比较地图等级。
