这条路线把已收录的 EA 规则整理成上手顺序。地图选择是建议；尚无覆盖六职业、全等级的统一效率测试，不能据此认定为最快练级方案。1.0 的地图和数值需重新核对。

## 出城前准备

1. 在[职业总览](/norr-wiki/classes/)比较战斗定位和制作专业，再阅读所选职业的技能说明。
2. 检查武器、职业限制和装备耐久。掉落装备先鉴定再比较，避免把隐藏属性当作零收益。
3. 阅读[技能系统](/norr-wiki/combat/skills/)，确认技能已经加入实际使用的技能栏；EA 自动战斗读取第 2–5 格。
4. 打开任务日志，确认正在推进的主线。主线任务与任务板是两套入口。

## Lv1–9：从 El Caspar 逐步探索

以下连接来自已收录的新手区资料，括号表示地图等级范围，不是强制推进等级。

| 路线 | 用途 |
|---|---|
| El Caspar → Elena's Crossroad（1–3）→ Akelay Foothills（4–6）→ Akelay Cave L1（4–6）→ L2（6–9） | 逐步提高怪物等级；战斗开始吃力时先回到较低等级区域 |
| El Caspar → Brisban Pond（1–3）→ Arodas Lakeshore（4） | 新手区探索的另一条支线；具体资源查地图清单 |
| El Caspar → Southern Foothill（1–3）→ Bay's Alley（4–6） | 根据当前任务和战斗表现选择的另一条路线 |

出新手村的门在最左侧。EA 中站到 gate 上还需执行换图操作，移动和视野控制见[地图、移动与传送](/norr-wiki/world/movement/)。

## 每次战斗之后

- **先拾取尸体**：EA 战斗经验在拾取时结算；只击杀不领取会漏掉经验。
- 如需拾荒材料，再在尸体仍存在时使用 Scavenging；战斗经验与拾荒经验分开计算。
- 看实际命中、战斗回合数和生命 / 法力消耗。单只怪的经验更高，不一定使单位时间收益更高。
- 回城时交任务并领取掉落窗中的奖励，再修理装备和补充消耗品。

## 什么时候换图？

| 当前表现 | 建议 |
|---|---|
| 怪物灰名、没有战斗经验 | 先排除未拾取，再寻找等级更合适的地图 |
| 能稳定完成战斗，移动时间也少 | 可以继续；升级后重新检查怪物颜色和经验 |
| 经常打空、战斗拖长 | 查命中与技能配置，再决定是否降低目标等级 |
| 死亡频繁、补给消耗过高 | 检查耐久、防御与抗性，回到可持续战斗的区域 |

EA 普通 PvE 死亡实测不掉经验，但仍有耐久、宠物 energy 和跑图成本；竞技场规则不同。

## Lv10 之后如何继续

现有资料不足以给出所有职业的 Lv10–满级最优地图链。可按[地图清单](/norr-wiki/world/maps/)筛选适合的区域，再结合[怪物图鉴](/norr-wiki/world/bestiary/)查目标。需要物品专家服务时，可查询 Elundi 等城镇设施；传送是否可用取决于已发现地图和 Spirit Essence。

每次更换练级区记录一小段实际游玩中的经验增量、耗时、死亡和补给消耗，再比较收益。不要只比较地图等级。
