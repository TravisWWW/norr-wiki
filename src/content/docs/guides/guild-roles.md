## 0. 三条前提（1.0）

1. **制作技能由职业决定，不能自由分配。** 每个职业固定可使用「5 项制作技能」，玩家只能选职业，不能单独选技能。
   → 所以「公会分配专业」= **分配职业**。
2. **8 项账号绑定专业**（Cooking 烹饪 + 7 项采集：Chopping / Farming / Fishing / Foraging / Mining / Quarrying / Scavenging）**所有职业都能学**，且**进度账号共享**。
   → 采集与烹饪**不需要分配**，每个成员自己练即可。
3. **10 项角色绑定制作专业**中，有 5 项只由单一职业可制作：

| 制作专业 | 唯一可制作职业 |
|---|---|
| Alchemy 炼金 | **Archmage** |
| Armorsmithing 铸甲 | **Zealot** |
| Carpentry 木工 | **Ranger** |
| Stonemasonry 石雕 | **Berserker** |
| Weaponsmithing 铸武 | **Berserker** |

> 1.0 变化：**Toolsmithing（工具锻造）并入 Weaponsmithing**，**Petbreeding（养宠）不再是独立专业**（宠物相关并入 Hunting 与 Petbreeder NPC）。

→ **要覆盖全部 10 个角色绑定制作专业，只需 4 个职业各一名成员：Archmage + Zealot + Ranger + Berserker。**

## 1. 推荐方案：6 人满编（全覆盖 + 冗余）

| 成员 | 职业 | 可使用制作专业 | 公会定位 |
|---|---|---|---|
| 1 | **Ranger 游侠** | **Carpentry**、Cartography、Cooking、Hunting、Leatherworking | 木料：出 Rod/Handle/Club，多个职业都需要 |
| 2 | **Archmage 法师** | **Alchemy**、Cartography、Cooking、Jeweling、Tailoring | 药水与宝珠，兼布甲 |
| 3 | **Berserker 狂战** | **Weaponsmithing**、**Stonemasonry**、Cooking、Hunting、Leatherworking | 武器与工具，兼石料 |
| 4 | **Zealot 狂热者** | **Armorsmithing**、Jeweling、Cartography、Cooking、Hunting | 重甲与金属线，兼珠宝 |
| 5 | **Rogue 盗贼** | Cartography、Cooking、Hunting、Leatherworking | 第二制图 / 制皮 / 狩猎，灵活补位 |
| 6 | **Druid 德鲁伊** | Cooking、Hunting、Leatherworking、Tailoring | 第二裁缝，宠物相关 |

建议：每人把 **8 项账号绑定专业**都练起来（进度账号共享，只需练一次）。采集**不是硬性门槛**——原材料也可以直接从 **Trading Post** 购买，只是自采更省金币。

## 2. 人不够时的优先级

### 4 人核心（推荐下限）
**Archmage + Zealot + Ranger + Berserker** —— 覆盖全部 10 个角色绑定制作专业。

### 3 人
**Archmage + Ranger + Berserker** —— 缺 **Armorsmithing**（Zealot 专属），重甲需从 Trading Post 补。

### 2 人及以下
只能靠 Trading Post 补料，建议至少保证 **Ranger（木工）** 和 **Archmage（炼金 + 珠宝）**。

## 3. 供应链：谁给谁供货

```
Chopping ──Log──► Carpentry ──Rod/Handle/Club──► Weaponsmithing / Hunting / Cartography
Mining ──Ore──► Armorsmithing / Weaponsmithing ──Ingot/Wire──► Jeweler ──Gem──► Cartography / Tailoring
Mining ──Geode──► Jeweler ──Gem──► Cartography / Tailoring / Weaponsmithing
Foraging ──Birdnest──► Seed ──► Alchemy ──Orb──► Weaponsmithing
Scavenging ──Tendon──► Hunting ──String──► Carpentry
Scavenging ──Hide──► Leatherworking ──Glove Base──► Hunting
Quarrying ──Stone──► Stonemasonry
Fishing ──Oily Fish Carcass──► Alchemy ──Fish Oil──► 药水
```

**四个关键环节**：Carpentry（木杆）、Jeweler（宝石）、Alchemy（宝珠）、Weaponsmithing（钉子）。若缺少对应职业，下游制作会受影响，建议优先安排。

## 4. 每人怎么练

- **制作升级快于采集**：搓**低阶、材料便宜的 T1 配方**刷等级效率最高。
- 采集主要在**需要材料**或**工具耐久富余**时做。
- **工具耐久**（1.0）：每次动作消耗 = **地图阶级 + 两者中的最高阶级**；工具损坏后在**城镇铁匠**处修复或使用**物品修复工具包**。详见[生活技能总览](/norr-wiki/professions/overview/)。
- **Crafting Queue（1.0）**：可在工坊把制作加入离线队列（3 槽，Noble +2），一边做别的事一边制作。详见[制作](/norr-wiki/professions/crafting/)。

## 5. 小结

> **采集与烹饪人人自己练；角色绑定制作按职业分。**
> 4 个职业（Archmage + Zealot + Ranger + Berserker）即可覆盖全部 10 个制作专业；
> 人少时优先保 **Ranger（木工）、Archmage（炼金）、Berserker（铸武/石雕）、Zealot（铸甲/珠宝）**。
