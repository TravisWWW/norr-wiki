> 所有职业均可学习 **8 项账号绑定专业**（Cooking + 7 项采集），因此原材料通常可以通过自行采集获得。
> 主要缺口来自**跨制作专业的半成品**（木杆 / 宝石 / 宝珠 / 钉子 / 皮套 / 弓弦），需要交易或其他职业协作。

## 1. 账号绑定专业 → 产出（全职业可用）

| 专业 | 采集点 | 产出材料（按 Tier 1-6） |
|---|---|---|
| Chopping 伐木 | Chopping Area | 各阶 **Log**、Hollowed Log、**Gall**（制墨水） |
| Farming 种植 | Farming Fields | Cotton Boll、Silkworm Cocoon、Jute、Nettle、Ramie（纤维）、Soil Lump（开 Spirit Seed） |
| Fishing 钓鱼 | Fishing Lake | Minnow、Shrimp、White Bass、Smallmouth/Largemouth Bass、**Oily Fish Carcass**（炼鱼油） |
| Foraging 采集 | Foraging Fields | Vegetables、Fruits、**Birdnest**（开红/蓝种子）、Random Produce |
| Mining 挖矿 | Mine | Copper/Iron/Tin Ore、Lump of Coal、Mithril/Valentaal/Galgonite Ore、**Geode**（开 Rough 宝石）、Spirit Ore |
| Quarrying 采石 | Quarry | Slate、Fieldstone、Soapstone、Sandstone、Laterite、Travertine、Basalt、Conglomerate、Spirit Stone |
| Scavenging 拾荒 | 击杀后尸体 | Hide、Bone、Chitin、Scale、Wing、Claw、Fang、Hoof、Tooth、Tendon、Skull、Goblin Ear/Hide、**Meat**、Soul(Boss) |
| Cooking 烹饪 | 制作台 | 食物与回复 Buff 类成品 |

> 注：Spirit Essence 来自 Spirit Berry/Flower/Log/Fish/Stone/Ore（由各采集专业附带产出），不是独立专业。

## 3. 每职业自给自足矩阵（1.0）

| 职业 | 可使用制作专业 | 原材料是否够 | 实际缺口 |
|---|---|---|---|
| **Archmage** | Alchemy / Cartography / Cooking / Jeweling / Tailoring | 是 | Cartography 缺 **Rod**(Carpentry)；Jeweling 缺 **Wire** |
| **Berserker** | Cooking / Hunting / Leatherworking / Weaponsmithing / Stonemasonry | 是 | Weaponsmithing 缺 **Handle/Club/Rod**(Carpentry) + **Orb**(Alchemy) + **宝石**(Jeweler)；Hunting 缺 **Rod** |
| **Druid** | Cooking / Hunting / Leatherworking / Tailoring | 是 | Hunting 缺 **Rod**(Carpentry)；Tailoring 缺 **宝石**(Jeweler) |
| **Ranger** | Cartography / Cooking / Hunting / Leatherworking / Carpentry | 是 | Carpentry 缺 **Nails**(Weaponsmithing)；Cartography 缺 **宝石**(Jeweler) |
| **Zealot** | Armorsmithing / Cartography / Cooking / Hunting / Jeweling | 是 | Cartography 缺 **Rod**(Carpentry)；Hunting 缺 **Rod** + **Glove Base**(Leatherworking) |
| **Rogue** | Cartography / Cooking / Hunting / Leatherworking | 是 | Cartography 缺 **Rod** + **宝石**；Hunting 缺 **Rod** |

### 读法
- **「原材料是否够」= 是**：因为 8 项账号绑定专业人人都有，矿/木/皮/鱼/种子都能自己弄。
- **缺口全是「制作成品」**：木杆(Rod/Handle/Club)、宝石(Gem)、宝珠(Orb)、钉子(Nails)、皮套(Glove Base)、弓弦(String)。这些在 **Trading Post** 都能买到，或靠另一个职业角色补。

## 4. 最关键的 4 个瓶颈专业

| 瓶颈专业 | 谁需要它 | 只有谁能做 |
|---|---|---|
| [**Carpentry**](/norr-wiki/professions/crafting-catalog/?prof=carpentry) | Cartography、Hunting、Weaponsmithing 都要 Rod/Handle/Club | Ranger |
| [**Jeweler**](/norr-wiki/professions/crafting-catalog/?prof=jeweling) | Cartography、Tailoring、Weaponsmithing 要宝石 | Archmage、Zealot |
| [**Alchemy**](/norr-wiki/professions/crafting-catalog/?prof=alchemy) | Weaponsmithing 要 Orb | Archmage |
| [**Weaponsmithing**](/norr-wiki/professions/crafting-catalog/?prof=weaponsmithing) | Carpentry 要 Nails（工具锻造已并入此专业） | Berserker |

> 生活技能进度账号共享，但**执行**必须用拥有该职业的角色。所以「补专业」= 开对应职业小号。
