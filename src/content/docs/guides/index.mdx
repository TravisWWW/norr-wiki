| 当前目标 | 推荐阅读 |

| 时间有限，安排日常 | [日常安排与资源预算](/norr-wiki/guides/daily-routine/) |
| 判断装备该换还是该强化 | [装备养成与更换决策](/norr-wiki/guides/equipment-progression/) |

| 公会要分配角色 | [公会职业分配方案](/norr-wiki/guides/guild-roles/) |
| 已选择 Zealot | [狂热者配装攻略](/norr-wiki/guides/zealot-build/) |
