## 怎么判断内容是否够用？

机制说明、图鉴记录和玩家攻略分别解决不同问题。页面数量包含目录与参考页，不代表所有游戏内容都已收录；图鉴记录数量也不表示全部掉落和随机词条已覆盖。

| 内容类型 | 当前能查什么 | 仍需补充什么 |
|---|---|---|
| 新手 | 官方 1.0 新手步骤、FAQ、游戏模式 | 各阶段地图效率对比 |
| 职业 | 六职业定位与官方 1.0 技能树、Zealot 配装 | 其余五职业分阶段 Build |
| 战斗与装备 | 属性、经验、鉴定、强化规则与已收录装备 | 多职业收益测试、装备来源和掉落概率核验 |
| 生活技能 | 8 账号绑定（7 采集 + 烹饪）、10 角色绑定制作、配方与职业矩阵 | 各专业独立升级路线、1.0 Masterworking 完整材料链 |
| 世界 | 1.0 游戏内实测怪物图鉴（199，含背景故事与掉落）、官方 1.0 怪物图鉴（132）、城镇与地图说明；EA 逐图清单 | 完整资源路线与新增区域 |
| 任务与挑战 | 主线记录、日常、副本清单和活动规则 | 逐个 Boss 战术、完整任务前置与奖励核验 |
| 经济与系统 | 货币、商人、公会、宠物等机制入口 | 实时市场价格、持续收益对比与 1.0 系统实测 |

## 资料状态与日期

下列状态来自页面自身元数据，不等于每条规则都适用于同一版本。“攻略建议 / 问答整理”表示汇编性质；“目录 / 参考”表示导航或编辑说明，未声明游戏验证状态。“—”表示没有单独记录核对日期，不能用文件更新时间代替实测时间。

## 补充资料的优先级

1. **版本适用与冲突**：正式版上线后，优先核对入口、经验、技能、死亡、日常和装备强化等高频规则。精炼风险阈值等现有口径差异需以实测与面板补证据。
2. **玩家最常卡住的步骤**：补各职业前期配置、任务前置、具体副本入口与 Boss 机制。
3. **长期养成**：补生活技能升级链、装备来源、宠物培养和稳定收益对比；数值结论注明角色条件和测量方法。
4. **来源可追溯性**：为公告与历史平衡调整补原始链接、发布者和日期，避免把测试服变化当作正式服事实。

## 参与完善
