## 内容改动明细

### 新增页面

- **`207 Quest Lore`**：任务界面可重读当前任务的故事与背景 → 并入[任务板与日志](/norr-wiki/quests/boards/)。
- **`209 Noble Status`**：账号级订阅的完整权益清单 → 并入[订阅与付费服务](/norr-wiki/systems/subscription/)。

### 内容改动

- **`165 Dungeons`（副本）**：**进入不再消耗钥匙**（选难度即可进入），钥匙改为**击败 Boss 后开 Lootbox** 时消耗；难度加成由「Gold / Magic Find」改为**经验 + Lootbox Magic Find**（Normal +0%/+0%、Nightmare +25%/+50%、Chaos +50%/+100%）；新增 Unique Rank 与难度说明 → 并入[副本与 Boss](/norr-wiki/quests/dungeons/)。
- **`236 游戏模式`**：术语由「专家 / 自强 / 专家自强」改为「**硬核 / 钢铁侠 / 硬核钢铁侠**」；**Ironman 专业槽位 5 → 6** → 并入[角色与账号](/norr-wiki/systems/characters/)、[生活技能总览](/norr-wiki/professions/overview/)。
- **`19 General Rules`（通用规则）**：账号政策收紧——除「每人一个账号」外新增「**每台设备一个账号**」；明确禁止共享 / 交易 / 出售 / 赠送 / 转让；以家人朋友名义注册不豁免 → 并入[通用规则](/norr-wiki/support/guidelines/general-rules/)。
- **`42 Terms of Service`**：第 20 节由「ADDENDUM」更名为「**GENERAL RULES AND ADDITIONAL POLICIES**」，明确通用规则构成 TOS 的一部分 → 并入[服务条款](/norr-wiki/support/guidelines/terms-of-service/)。
- **`178 Referrals`**：措辞微调（Grave Wyrmstone → Grave Wyrmstone Skin、Wyrm Acolyte Skin → Wyrm Acolyte Character Skin、Wyrmling Pet → Wyrmling Pet Skin）。

## 技能与模拟器

- **技能定义未变化**：六个职业页（`136`–`141`）与技能书页（`94`）的技能 tooltip（技能名 / id / 上限 / 解锁等级）与 2026-10-15 完全一致。
- **技能等级上限已确认 = 10**（此前本站记为「1.0 未公布，待确认」）：
  - 官方 1.0 Wiki 六个职业页把**全部 170 个技能**都标为 `skill-level=10`，页面即以 **Lv.10 口径**展示（`wiki.js` 把 `skill-level` 当作 tooltip 的显示等级）。
  - 1.0 客户端 `skillbook.min.js`（P20250820）的加点逻辑把上限**硬编码为 `0xa`（=10）**：结果 >10 时拒绝并提示 `Skill Maxed`，「+」按钮在等级 ≥10 时禁用。
  - 旁证：1.0 每级增量约为 EA 的 **2 倍**（Blade Mastery：EA Lv.20 = +43% / +24%，1.0 Lv.10 = +41% / +23%），即「等级数减半、每级增量加倍、满级值基本不变」。EA 帮助页以 `(Lv. 20)` 展示，实测 Lv17 角色可点到 16 → EA 上限 20。
- **模拟器已更新**：`public/talent/index.html` 的**技能上限由 20 改为 10**，并**移除 EA 数据集**（模拟器现为 **1.0 专用**）；[技能系统](/norr-wiki/combat/skills/)、[1.0 职业技能变化详解](/norr-wiki/release/v1-class-skill-changes/) 同步更正。
- 仍待确认：1.0 是否保留 EA 的「技能等级 ≤ 角色等级 − 1」限制。
