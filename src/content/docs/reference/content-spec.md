本站以**游戏百科、规则说明与玩家攻略**为主体，不收录个人研发过程、自动化脚本调试与账号操作日志。

## 收录范围

| 内容 | 处理 |
|---|---|
| 游戏规则、职业属性、技能说明、装备效果 | 保留 |
| 游戏内操作、地图、任务、制作配方 | 保留并规范化 |
| 实测公式、掉落率、经验数据 | 精简并标注适用版本与条件 |
| HTTP 请求、接口、HTML 属性、Cookie、脚本代码 | 不收录 |
| 个人角色等级、背包快照、单次刷怪日志 | 不收录（必要时提取结论） |
| 测试过程中的争论、纠错记录 | 合并为最终结论 |
| 职业 Build、练级路线、赚钱方法 | 归入「攻略」栏目 |
| 尚未验证的机制猜想 | 不作为确定事实发布 |

## 正文结构

页面简介 → 核心规则或属性 → 具体机制 → 条件与限制 → 相关页面 → 资料来源。

## 语言风格

- 使用客观、简洁、第三人称的说明文字。
- 避免「本站」「我发现」「用户指出」「重大发现」等过程性表达。
- 区分**机制说明**（游戏如何运作，可写确定）、**使用建议**（基于机制的常见选择）与**适用条件**。
- 术语首次出现采用「中文名称（英文名称）」，其后统一。

## 资料状态（版本标记）

正式版（1.0 / Steam）尚未完全公开规则，因此每页正文与关键结论按**三种状态**标注，页面标题下方也会显示该页的整体状态：

| 状态 | 含义 |
|---|---|
| **EA 版已验证** | 基于 `legacy.norroth.com`（Early Access）实测或官方帮助文档确认，**不代表 1.0 已生效**。 |
| **1.0 官方已公布** | 官方商店页或开发者公告已明确公布，但具体数值/规则可能尚未公开。 |
| **1.0 上线后待验证** | EA 版数据，正式版上线后需要重新核对。 |

- 状态是**规则级**而非整页级：同一页面可同时包含「1.0 官方确认」与「EA 实测、1.0 待验证」的内容，逐条标注。
- 对随机机制、样本推断与未确认信息，保留必要的不确定性说明。
- 不把「预计更新」写成「现有机制」；正式版未公布的具体规则不提前赋予确定性。

## 术语与译名

游戏客户端的中文为 AI 辅助翻译，官方表示会依据社区反馈调整。因此职业、技能、属性、物品、地图与 NPC 均以**英文原名**为稳定标识，中文名仅作显示：

| 字段 | 用途 |
|---|---|
| 英文原名 | 相对稳定的识别名称 |
| 官方中文名称 | 记录对应版本游戏内使用的译名 |
| Wiki 常用名称 | 兼容玩家惯用简称与检索别名 |

正文首次出现采用「中文名称（英文名称）」，后续统一；官方修改翻译时只需更新显示名，不影响关联。

## 发布限制

不发布真实账号凭据、兑换码、私人邮件、个人文件路径、自动化脚本运行日志，以及与正常玩法无关的内部接口细节。

## 页面维护

正文仅保留当前有效规则；历史变更可在页末以简短版本记录说明，不按测试时间逐次追加整段研究笔记。
