本页面向**编辑者**，说明本站的收录范围、正文结构、语言风格与资料状态标注规则。
完整规范见仓库根目录的 [CONTRIBUTING.md](https://github.com/TravisWWW/norr-wiki/blob/main/CONTRIBUTING.md)。

## 收录范围（摘要）

| 内容 | 处理 |
|---|---|
| 游戏规则、职业属性、技能说明、装备效果 | 保留 |
| 游戏内操作、地图、任务、制作配方 | 保留并规范化 |
| 实测公式、掉落率、经验数据 | 精简并标注适用版本与条件 |
| HTTP 请求、接口、脚本代码、个人账号与日志 | 不收录 |
| 职业 Build、练级路线、赚钱方法 | 归入「攻略」栏目 |
| 尚未验证的机制猜想 | 不作为确定事实发布 |

## 资料状态（版本标记）

每页标题下方会显示该页的整体状态：

| 状态 | 含义 |
|---|---|
| **EA 版已验证** | 基于 `legacy.norroth.com`（Early Access）实测或官方帮助文档确认，**不代表 1.0 已生效**。 |
| **1.0 官方已公布** | 官方商店页或开发者公告已明确公布，但具体数值/规则可能尚未公开。 |
| **1.0 上线后待验证** | EA 版数据，正式版上线后需要重新核对。 |

> 状态是**规则级**而非整页级：同一页面可同时包含「1.0 官方确认」与「EA 实测、1.0 待验证」的内容，逐条标注。

## 术语与译名

职业、技能、属性、物品、地图与 NPC 均以**英文原名**为稳定标识，中文名仅作显示；首次出现采用「中文名称（英文名称）」，其后统一。
