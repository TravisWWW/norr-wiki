本站内容来自多个渠道，**证据等级不同**，阅读时请先看页面标题下方的**资料状态徽标**，再看正文中的口径标注。

## 证据等级

| 等级 | 标注 | 含义 |
|---|---|---|
| **官方规则** | 【官方】 | 游戏内帮助文档（Help File）明确写出的规则 |
| **官方公告** | 【官方 · 日期】 | 官方 Discord 公告 / 开发日志 / 开发者发言 |
| **EA 实测** | 【实测】 | 本项目在 EA（Legacy）服务器实际验证 |
| **社区推断** | 【社区】 | 玩家统计或推断，未独立验证 |

> **重要区分**：「开发者在 Discord 说过」与「官方宣布正式版最终采用」**证据等级不同**。
> 前者是**开发日志 / 测试期口径**，后者才是**正式版结论**。本站对 1.0 内容一律标注为「**1.0 官方已公布**」，均**待正式服实测**。

## 资料状态徽标

页面标题下方会显示资料状态：

| 徽标 | 含义 |
|---|---|
| **EA 版已验证** | 内容来自 EA 版实测，可直接参考 |
| **1.0 官方已公布** | 来自官方公告，**未在正式服实测** |
| **1.0 待验证** | 官方已提及但细节不足，需上线后核实 |
| **EA 已验证 · 1.0 待验证** | 页面同时含 EA 实测与 1.0 公告内容，注意区分 |

## 版本适用

| 版本 | 说明 |
|---|---|
| **EA（Legacy）** | `legacy.norroth.com`，v0.8.x；本站大量实测数据的来源 |
| **1.0 测试服** | `test.norroth.com`（2026-05-27 开放公开测试） |
| **1.0 正式服** | 2026-10-16 上线的正式版 |

**EA 数值不代表已在 1.0 生效**；两个服务器账号与数据均不互通。

## 来源字段

页面的 `sources` 元数据按下表记录（尽可能补全）：

| 字段 | 作用 |
|---|---|
| **消息日期** | 判断该结论的新旧 |
| **频道与发布者** | 判断是否为开发者正式发言 |
| **Discord 消息链接** | 追溯原文 |
| **资料性质** | 正式公告 / 开发日志 / 测试反馈 / 玩家讨论 |
| **适用版本** | Legacy / 1.0 测试服 / 1.0 正式服 |
| **当前状态** | 已公布 / 已被后续消息取代 / 已实测 / 待验证 |

> **已知局限**：本站 1.0 内容整理自官方 Discord 导出，**部分条目尚未补齐原始消息链接与发布者**。
> 职业平衡类存在**相互覆盖的历史调整**（例如 Attack Speed 的额外打击上限曾调整后回退），
> 正文已尽量标注**最新有效结论**与**时间线**；如需精确复核请以游戏内 tooltip 与帮助文件为准。
