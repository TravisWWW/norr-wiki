## 内容改动明细

### 新增页面

- **`238 公会地牢 / Guild Dungeon`**：公会领地内的**地牢传送门**——可直接跳到**已发现**的世界地牢，无需亲自走到地图入口；默认以 **Normal** 难度开始；与「传送到城市」的**公会传送门**不同 → 并入[公会系统](/norr-wiki/systems/guilds/)。

### 内容改动

- **`38 城镇与城市`**：城镇 **14 → 16**，新增 **Dominion Spire（Lv50 / Tier 6 / 2680-1547）**、**Laen Dorei（Lv50 / Tier 6 / 3153-1085）** → 并入[地图、移动与传送](/norr-wiki/world/movement/)。
- **`56 首领`**：Boss **16 → 23**。新增 5 个 **Lv60** Boss（Angry Snowman / Drake Boss / Hollow Phantom / Mutant Plant / Oculus）、**Ruin Guard（Lv13）**、**Real Medusa（Lv20）**；改名 `Lord Marious`、`Baron, Manor Lord`、`Devourer`、`Leech Demon`、`Yurk`；`Devourer` 等级 Lv10 → **Lv12**；多处世界坐标更新 → 并入[副本与 Boss](/norr-wiki/quests/dungeons/)。

- **`112 货币`**：由空页补全——**Currency Pouch（货币袋）** 机制（独立于背包、**账号共享**（Ironman 各角色独立）、有上限且到顶变红；分为日常 / 冒险 / 钥匙与工具 / 活动四类） → 并入[经济与货币](/norr-wiki/systems/economy/)。
- **`117 烹饪`**：新增 **7 条宠物食品配方**（Pet Food T1 **+3**、T5 **+4**）。

## 技能与模拟器

- **技能数量与定义未变**：六个职业页（`136`–`141`）与技能书页（`94`）的技能 tooltip（技能名 / id / 上限 / 解锁等级）与 2026-10-16 完全一致，技能总数仍为 **444** 条。
- **客户端脚本构建已更换**：官方 Wiki 引用的游戏脚本目录由 `includes/js/P20250820/` 变为 `includes/js/P20261019/`。对比两份 `tooltip_texts.js` 的 `skill_json`，**4 个德鲁伊长矛系技能效果确有改动**（新增或提高「流血伤害」）：
  - `lacerate`（撕裂）：新增 **+10** 流血伤害（每级 **+5**），并保留 **+1%** 流血伤害（每级 **+4%**）；
  - `javelin_throw`（投掷标枪）：新增 **+20** 流血伤害（每级 **+10**）；
  - `wildwood_impale`（荒野穿刺）：新增 **+30** 流血伤害（每级 **+10**）；
  - `pack_attack`（群狼攻击）：流血伤害 **40 → 50**（每级 **+10**）。
- **已修复解析缺陷并重算数值**：此前生成脚本按「词条出现位置」把基础值 / 每级值配对，遇到**重复属性词条**（如 `bleed_damage,10|bleed_damage,1%`）或**扁平值 + 百分比并存**时会错配、并丢弃新增的扁平词条。现已改为按 **(属性, 单位)** 聚合，与游戏客户端 `parseEffectString` 一致；对全部 **220** 个模拟器技能逐条比对游戏 `generateSkillTooltip`，**数值零差异**；并修正了模拟器把 `direct` / `ability` 技能的「武器 + **魔法**伤害」误显示为「武器 + 物理伤害」的问题（共 16 个技能，含游侠的 `pin_down` / `boltnet_shot` / `snare_trap` / `dazing_trap` / `poison_cloud_trap` / `bear_trap` 等）。
- 官方职业页现提供**中文技能分组名**（如 Bow Mastery → 弓箭专精、Arcane Mastery → 奥术精通）；本站职业页与[天赋模拟器](/norr-wiki/tools/talent/)已按官方中文名展示。
- 模拟器**技能上限仍为 10 级**（见[官方 1.0 Wiki 更新对照（2026-10-16）](/norr-wiki/reference/official-wiki-2026-10-16/)）。
