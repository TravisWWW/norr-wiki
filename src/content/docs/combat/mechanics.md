## 敌人名称颜色与等级差【官方 1.0 Wiki】

敌人名字颜色表示**相对你等级**的强弱与经验：

| 颜色 | 含义 | 经验 |
|---|---|---|
| 灰 Gray | 远低于你 | **0**（太弱，不给经验） |
| 绿 Green | 略低 | 减少 |
| 黄 Yellow | 与你同级 | 正常 |
| 橙 Orange | 高于你 | 更多，更硬 |
| 红 Red | 明显高于你 | 非常危险，奖励最多 |

## 敌人阶级（星级）【官方 1.0 Wiki】

星级显示在名字旁，并有不同的灵气颜色；星级越高，**属性 / 生命越高，掉落与战斗经验越多**。

| 阶级 | 属性提升 |
|---|---|
| Champion 冠军 | 小幅提升 |
| Rare 稀有 | 中等提升 |
| Elite 精英 | 大幅提升 |

## 精英词缀（Elite Prefixes）【官方 1.0 Wiki】

只有 **Elite** 稀有度的敌人会随机获得**一个词缀**，显示在名字前（如 `Hellfire Wolf`）。词缀按敌人类型（Humanoid / Undead / Animal 等）随机抽取，可提供额外属性、战斗技能、开场 / 死亡效果，并附加一个敌人类型。

| 词缀 | 效果 |
|---|---|
| Arcanwall | 护盾 + Bone Shield 技能 + Fortified 类型 |
| Colossal | 巨额生命 + Giant 类型 |
| Corrupted | 暗影伤害 / 抗性 + 暗影攻击 + 开场 Spectral Fear + 死亡 Last Curse |
| Divine | 光明伤害 / 抗性 + 光明攻击 + 可能开场致盲 + Flying 类型 |
| Glacierborn | 冰冷伤害 / 抗性 + 冰冷攻击 + Cryophile 类型 |
| Hellfire | 火焰伤害 / 抗性 + 火焰攻击 + 死亡 Explosive Demise |
| Manatapper | 额外法力 + 偷取敌人法力 |
| Plaguefang | 毒素伤害 / 抗性 + 强力毒攻击 + 死亡额外效果 |
| Powerful | 提高基础伤害 |
| Runeburst | 奥术伤害 / 抗性 + 奥术攻击 |
| Stormlash | 闪电伤害 / 抗性 + 闪电攻击 |
| Thick Skinned | 提高基础防御 + Fortified 类型 |
| Vampiric | 生命偷取 + Bite 技能 + 开场 Blood Hunger |

## 阵营（Alignment）【官方 1.0 Wiki】

创建角色时选择 **Light（光明）** 或 **Dark（黑暗）**，影响可加入的公会阵营、成就与阵营点数、宠物表情与任务对话，并与部分技能（如 Zealot 光 / 暗系）绑定。

## 攻击类型与额外打击【官方 1.0 Wiki】

攻速更高者**先手**。攻速提供额外的武器打击次数（**不作用于 AoE、DoT 与增益**）。

- 额外打击公式：`(Attack Speed − 100) ÷ (800 − level × 5)`，**最多 3 次**额外打击。
- **多段递减**：第 1 段全额，之后每段 × (1 − (n−1) × 0.20)，**保底为首段的 40%**。
  - 2 段：100% / 80%；3 段：100% / 80% / 60%；4 段：100% / 80% / 60% / 40%。

| 技能类型 | 可 miss | 可闪避 | 吃攻速额外打击 |
|---|---|---|---|
| Melee / Ranged / Spell | ✔ | ✔ | ✔ |
| Direct | ✔ | ✔ | ✘ |
| Ability | ✘ | ✘ | ✘ |
| AoE / DoT / Buff / Debuff | ✘ | ✘ | ✘ |

## 伤害结算【官方 1.0 Wiki】

- 攻击可被**格挡（Block）**与**闪避（Evade）**；暴击（Crit）造成额外伤害。
- **格挡减免**：`(格挡值 − 攻击者护甲穿透) ÷ (1 + 技能中的元素数量)`；AoE 与 DoT 不可格挡，幽灵类攻击者不可格挡。
- **荆棘反弹**：`荆棘伤害 × 0.30`，**不被防御减免**，仅近战命中且防守方未闪避时触发。
- **逃跑（Flee）**：成功率按**敌人等级与稀有度**计算；高等级 / Elite / Boss 更难逃。

## 异常状态与控制【官方 1.0 Wiki】

| 状态 | 持续 | 命中 / DoT 分配 | 减免 |
|---|---|---|---|
| 流血 Bleed（Wounded） | 3 回合 | 10% / 90%（+20%） | 防御；构装体与不死族免疫；阻止生命回复 |
| 燃烧 Burn | 2 回合 | 50% / 50%（+10%） | 火焰抗性 |
| 亵渎 Defile | 3 回合 | 35% / 65%（+20%） | 暗影抗性 |
| 疯狂 Delirious | 3 回合 | 30% / 70%（+20%） | 基础抗性 |
| 感染 Infect | 4 回合 | 25% / 75%（+30%） | 毒素抗性 |
| 圣辉 Radiant | 3 回合 | 35% / 65%（+20%） | 光明抗性 |

控制类：**致盲**（1 回合，锁定的近战 / 远程 / 法术 / 直接攻击必定未命中）、**混乱**（2 回合，命中减半、无法暴击）、
**恐惧**（2 回合，物理 / 法术伤害减半、攻速为 0、无法闪避）、**冻结**（2 回合，攻速移除、总攻击次数减半、无法闪避）、
**定身**（1 回合，无法近战，也无法逃跑）、**沉默**（约 1 回合，无法施法 / 技能，普攻仍可用）、**眩晕**（1 回合，无法行动与闪避）。

> 元素伤害的副作用：奥术→沉默、冰冷→冻结、暗影→恐惧、火焰→燃烧、光明→致盲、闪电→混乱、毒素→感染。
> 巨人 / 幽灵等类型对部分效果免疫。

## 自动战斗【官方 1.0 Wiki】

- 开启 **Auto Combat** 后，系统**只使用战斗技能栏（Combat Hotbar）中的技能**，每回合按**优先级、生命、法力**等因素自动选择最合适的技能或行动。
- 技能栏第 1 格为普通攻击（Basic Attack）。
- 药水阈值 **HP / MP 分开设置**。
