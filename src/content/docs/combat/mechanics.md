## 结论速览

- 官方确认 Norroth 采用**回合制战斗**；本页其余数值为 EA 版实测，1.0 待验证。
- 敌人名字颜色表示**相对等级**：灰名不给经验，黄名同级，红名最多但危险。
- 攻速决定**额外打击**次数，最多 3 次；多段伤害逐段递减。
- **自动战斗只使用技能栏第 2~5 格**（第 1 格固定为普通攻击），按格号顺序施放「不在冷却」的技能。
- 异常状态各有独立规则；部分（沉默 / 恐惧 / 窃取）可被韧性抵抗。
- 战斗按回合推进，每回合约数秒。

## 战斗流程

战斗以**回合**推进：双方每回合各行动一次，先手由攻速决定。战斗结束后角色回到可移动状态，可继续前往下一个战斗格。

## 敌人名称颜色与等级差

敌人名字颜色表示相对你等级：

| 颜色 | 含义 | 经验 |
|---|---|---|
| 灰 Gray | 远低于你 | 0 |
| 绿 Green | 略低 | 减少 |
| 黄 Yellow | 与你同级 | 正常 |
| 橙 Orange | 高于你 | 更多 |
| 红 Red | 远高于你 | 危险，最多 |

星级（Champion < Rare < Elite）提升血量与属性，并额外给战利品和战斗经验。带词缀的精英怪经验约为普通怪的 2 倍。

## 攻击类型与额外打击

> 攻速更高者先手。攻速提供额外的武器打击次数（不作用于 AoE、DoT 与增益）。

- 额外打击公式：`(Attack Speed − 100) ÷ (800 − level × 5)`，最多 3 次额外打击。
- 例：Lv20 角色拿 1 次额外打击需攻速 ≥ 800，拿满 3 次需 ≥ 2200。
- **多段递减**：第 1 段为全额，之后每段 × (1 − (n−1) × 0.20)，**保底为首段的 40%**。
  - 2 段：100% / 80%
  - 3 段：100% / 80% / 60%
  - 4 段：100% / 80% / 60% / 40%
- 冷却按回合计算，多段打击不会跳过冷却。

> **资料状态**：额外打击公式来自 EA 版资料，**1.0 待验证**；正式版上线前不宜据此做精确预算。

哪些技能吃额外打击：

| 类型 | 可 miss | 可闪避 | 吃攻速额外打击 |
|---|---|---|---|
| Melee / Ranged / Spell | 是 | 是 | 是 |
| Direct | 是 | 是 | 否 |
| Ability | 否 | 否 | 否 |
| AoE / DoT / Buff / Debuff | 否 | 否 | 否（AoE/DoT 永不 miss） |

## 伤害结算

- 攻击可被格挡（Block）与闪避（Evade），暴击（Crit）造成额外伤害。
- 多元素法术伤害按元素**平均分摊**后各自结算。
- 荆棘伤害（Thorn Damage）：按总荆棘值的 30% 以真实伤害反弹给近战攻击者（防守方未闪避时）。
- 逃跑成功率上限约 80%。

## 异常状态

| 状态 | 效果 | 中文 |
|---|---|---|
| Root | 1 回合不能移动、不能近战攻击（法术可施放） | 定身 |
| Silence | 1 回合不能施放法术（普攻可打） | 沉默 |
| Stun | 1 回合不能行动 | 眩晕 |
| Radiant | 3 回合光系持续伤害 | 光系 DoT |
| Bleed / Wound | 3 回合流血；Wound 期间无法通过生命回复回血 | 流血 / 禁疗 |
| Blind | 2 回合内攻击与指向法术必定 miss（AoE/DoT 不受影响） | 致盲 |

- 韧性（Resilience）只降低生命窃取 / 法力窃取 / 沉默 / 恐惧，不降低定身与眩晕。
- 技能描述中的「+X% to Root」是**施加概率**，不是伤害加成。

## 自动战斗

- 开启自动战斗后，只使用技能栏**第 2~5 格**；第 1 格固定为普通攻击（Basic Attack）。
- 施放规则：**按格号顺序选择第一个不在冷却的技能**，冷却中的技能会被跳过并回落到普通攻击。
- 因此把最常用的主动技能放在第 2 格；第 6 格及以后不会被自动战斗使用。
- 技能耗蓝是主要限制，配装时需考虑回蓝 / 吸蓝。

## 1.0 变化【官方已公布】

> 以下为 1.0 官方公告口径，**未在正式服实测**；本页上方规则为 **EA 版**。

- **自动战斗重做**：改为 **impact-score（影响分）决策系统**，更聪明地选择技能与药水；**只从当前技能栏取技能**；同时适用于 **PvE 与 PvP**。因敌人也变聪明，**敌人整体强度略微下调**。
- **药水阈值**：HP / MP **分开设置**。
- **Attack Speed**：Bonus Strikes 阈值 1400 → **1900**，**上限 3 额外打击**。
- **Max Evasion**：上限 **60% → 50%**（Rogue 满级被动可达 60%）。
- **Critical Chance**：效果 **+33%**；**敌人暴击 -33%**。
- **Counter Strike**：**属性移除**，相关职业被动改写。
- **Life Steal 公式**：`(LS ÷ 5) ÷ (LS ÷ 5 + 400 + 85 × level)`（分母由 ÷4 改 ÷5）。
- **Blind**：**Boss 免疫**。
- **Flee（逃跑）**：改为**按敌人等级与稀有度**计算（原约 80% 固定）；高等级 / Elite / Boss 更难逃。
- **Bonus Strike 惩罚伤害**：改到**第 2 回合后**开始下降。
- **伤害类型**：伤害加成**只放大对应类型的技能**（见[角色属性](/norr-wiki/combat/attributes/)）。

详见 [1.0 机制变更](/norr-wiki/release/v1-changes/) 与 [1.0 职业平衡](/norr-wiki/release/v1-class-balance/)。

## 敌人阶级、词缀与阵营【1.0 官方 Wiki】

- **阶级（星级）**由名字旁的星星与灵气颜色显示：**冠军 Champion（蓝）**属性提升较少、**稀有 Rare（黄）**中等、**精英 Elite（紫）**大幅提升。星级越高，掉落与战斗经验越多。
- **精英词缀（Elite Prefixes）**：只有 **Elite** 稀有度的敌人会随机获得一个词缀（显示在名字前，如 `Hellfire Wolf`），按敌人类型（Humanoid / Undead / Animal 等）随机抽取。词缀可提供额外属性、战斗技能、开场/死亡效果，并附加一个敌人类型。

| 词缀 | 效果 |
|---|---|
| Arcanwall | 护盾 + Bone Shield 技能 + Fortified 类型 |
| Colossal | 巨额生命 + Giant 类型 |
| Corrupted | 暗影伤害/抗性 + 暗影攻击 + 开场 Spectral Fear + 死亡 Last Curse |
| Divine | 光明伤害/抗性 + 可能致盲 + Flying 类型 |
| Glacierborn | 冰冷伤害/抗性 + Cryophile 类型 |
| Hellfire | 火焰伤害/抗性 + 死亡 Explosive Demise |
| Manatapper | 额外法力 + 偷取敌人法力 |
| Plaguefang | 毒素伤害/抗性 + 死亡额外效果 |
| Powerful | 提高基础伤害 |
| Runeburst | 奥术伤害/抗性 |
| Stormlash | 闪电伤害/抗性 |
| Thick Skinned | 提高基础防御 + Fortified 类型 |
| Vampiric | 生命偷取 + Bite 技能 + 开场 Blood Hunger |

**阵营（Alignment）**：创建角色时选择 **Light（光明）** 或 **Dark（黑暗）**，影响可加入的公会阵营、成就与阵营点数、宠物表情与任务对话，并与部分技能（如 Zealot 光/暗系）绑定。
