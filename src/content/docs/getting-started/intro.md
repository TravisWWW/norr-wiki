## 结论速览

- Norroth（Steam 上名为 **Norroth Online**）是一款**手绘风、格子制（tile-based）**的 MMORPG。
- **1.0 正式版**通过 **Steam** 发行，官方商店页已列出 **Windows / macOS / Linux** 系统需求，并提供简体中文与繁体中文界面。
- 游戏内知识库是官方 **Wiki**（wiki.norroth.com）与游戏内提示。
- 升级的核心口诀：**做任务、打同级怪、把点数花完、阶梯到了就换装**。

游戏以格子（tile）为单位移动与战斗，包含 **6 个职业**、生活技能（采集 / 制作）、副本、宠物、公会、住房、远征（航海）与 PvP 等系统。

## 新手第一步（官方新手指南）

### 1. 正确升级

- **每升一级**：获得 **5 点属性点 + 1 点技能点**。
- 每次升级后打开**头像 → 属性与技能**，**务必把点数分配完**（未用点数 = 更弱的战斗）。

### 2. 跟着任务走

- **紫 = 主线**（优先推进）、**橙 = 支线**（经验与教学）、**蓝 = 日常**（每日经验）、**绿 = 可交付**（别留奖励不拿）。

### 3. 聪明地战斗

- 与**同级（绿 / 黄）**敌人战斗；避开橙 / 红，除非你准备好了。
- **灰名怪几乎不给经验**，直接跳过。
- 熟悉技能后，可在**设置**中开启**自动战斗（Auto Combat）**。

### 4. 装备与阶梯

- 1-9 级 = **1 阶**（铜 / 污浊）；10-19 = **2 阶**（铁 / 废料）；20-29 = **3 阶**（锡）……
- 持续提升装备的**品质（Quality）与等级**，对伤害 / 防御影响很大。
- **不要在低级物品上投入巨额成本**。

### 5. 金钱与材料

- **金币**：在商人（Vendor）或交易行（Trading Post）卖物。
- **灵气精华（Spirit Essence）**：开灵魂物品或分解垃圾装备。
- **稀有度代币（Rarity Tokens）**：升级奖励，留到后面换更好的装备。
- **钥匙（Keys）**：开保险箱 / 早期地下城（铜 > 铁）。

### 6. 背包与城镇

- 背包初始 **50 格**，多余物品存城镇银行。
- 第一座城市：**El Caspar**（新手教程之后）。
- 约 10 级到 **Elundi / Owranbu**（2 阶枢纽）。
- 城镇提供**银行、交易行、专业训练师与邮件**。

### 7. 采集与制造

- 在**你的阶梯**上采集：铜（1-9）、铁（10-19）、锡（20-29）。
- 携带**匹配的工具**——工具损坏 = 无法采集。
- 采集进度**账号共享**；每个角色最多 **3 个专业**。

### 8. 生存提示

- 随身带足**生命药水**（可拾取、向炼金 NPC 购买或与玩家交易）。
- **进食**可获得额外的回复 Buff。
- **9 级以下死亡**：在泉水（Fountain）满血复活；**9 级及以上**：半血复活。

## 游戏模式（1.0）

开局时可选择**特殊路线**：**Hardcore（硬核）/ Ironman（钢铁侠）/ Hardcore Ironman（硬核钢铁侠）**。该选择在第一次出生时于**泉水（Fountain of Rebirth）**与 **Eldritch Caretaker** 对话完成。

|  | Normal | Hardcore | Ironman | HC Ironman |
|---|---|---|---|---|
| 死亡后复活 | ✔ | ✘ | ✔ | 🡇 |
| 灌注复活（Infusion revive） | ✔ | ✘ | ✔ | ✘ |
| 交易行（Trading Post） | ✔ | ✔ | ✘ | ✘ |
| 邮件附件 | ✔ | ✔ | ✘ | ✘ |
| 向 NPC 购买材料 | ✔ | ✔ | ✘ | ✘ |
| 公会银行 / 军械库 | ✔ | ✔ | ✘ | ✘ |
| 账号共享银行 | ✔ | ✔ | ✘ | ✘ |
| 账号共享钱包 | ✔ | ✔ | ✘ | ✘ |
| 专业槽位 | 3 | 3 | **6** | **6** |

- **Hardcore**：死亡即永久删号（不能复活、无灌注复活）；20 级起死亡会在世界频道公告。金币、银行、邮件战利品、交易行与图鉴进度留在 Hardcore 经济中，与同账号其他 Hardcore 角色共享。
- **Ironman**：一切靠自己——无交易行、无邮件附件、不向 NPC 买材料、无公会银行 / 军械库；个人银行与货币**不与其他角色共享**。作为补偿，可训练 **6 个专业**（普通为 3）。
- **Hardcore Ironman**：同时遵守 Ironman 与 Hardcore 规则；死亡后**降级为普通 Ironman**。

## 界面与背包

- **背包**即角色的随身背包，窗口标题显示**已用 / 总格数**；满了需先腾出空间。
- **悬停**物品格查看提示；窗口底部搜索框输入 **≥2 个字符**即可高亮匹配物品。
- **双击**物品通常执行最合适的操作（装备已鉴定装备、鉴定未知装备、使用消耗品 / 材料）。
- **右键（或移动端点按）**打开物品操作菜单：Identify / Equip / Use / Use All / Deposit / Details / Salvage / Return / Lock / Unlock / Delete 等。部分操作有场景限制（如 Deposit 需打开银行，Salvage 不能在战斗 / PvP / 远征中使用）。
- **货币袋（Currency Pouch）**：金币旁的袋子图标，集中查看特殊货币与代币。
- **Merge**：合并拆分堆叠，整理背包。
- **额外格位**：背包装备与部分宠物可通过 **+ Slots** 属性增加格位。

## 传送与快速旅行（1.0）

- **Home Scrolls（回城卷轴）**：由 **Cartography（制图）** 制作，可传送到已访问过的指定城镇。
- **Teleportation Scrolls（传送卷轴）**：可传送到任何**已访问过**的地图（地下城与秘密地图除外）。来源：活动商人处兑换门票、开 Party Popper 礼物、完成特殊订单板任务、在星界市场（Celestial Market）购买。
- **Infusion Stones（灌注石）**：用于在**灌注总览**中升级传送技能；每颗可让你**跳 200 个节点**（点击视野内任意节点直接传送，每跳一格消耗一次）。
- **Waygates（传送门网络）**：在城市与部分野外地图，站上传送门（或使用**公会传送门**）打开旅行窗口，选择目的地并 Travel 即可。费用按目的地地图阶梯计算：**Tier² × 50 灵气精华**（T1=50、T2=200、T3=450、T4=800、T5=1250、T6=1800）。**传送到 El Caspar 永远免费**；**Noble 订阅者**可免费传送到任何已发现的城市（野外传送门仍收费）。目的地需**已发现**才会出现。
