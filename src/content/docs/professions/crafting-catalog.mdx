Norroth 的 **13 个制作专业**共有 1,200+ 条配方。用下面的筛选器按 **专业 / 物品类型 / Tier / 物品等级** 过滤，或在搜索框输入 **成品名或材料名**（输入材料名即可反查它由谁制作、又用在哪里）。点击任意一行展开完整材料、配方变体与基础属性。

## 字段说明

- **物品等级（Lv）**：该成品自身的需求等级（装备 / 使用门槛）。它与**制作解锁等级**不同——每个子类的配方按 **Lv1 / Lv5 / Lv9** 三档解锁（官方口径），解锁等级不随物品等级线性变化。
- **Tier**：成品所属的材料阶级（T1–T5）。药水按种子阶级（Tiny → Greater ≈ T1 → T5）归类。
- **配方变体**：同一成品的多种等价配方（例如不同宝石的同一件首饰、可互相替代的药水材料）已合并为一条，展开后列出全部。
- **资料未提供**：官方帮助未标注该成品的属性或材料时显示为「资料未提供」，不代表该成品没有属性。
- **覆盖范围**：当前收录 **T1–T5**；T6（Valentaal / Ash / Bamboo / Travertine / Northern Pike 等）的详细配方官方尚未提供，待补充。
