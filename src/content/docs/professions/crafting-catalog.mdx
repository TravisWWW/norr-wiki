## 字段说明

- **物品等级（Lv）**：该成品自身的需求等级（装备 / 使用门槛）。它与**制作解锁等级**不同——每个子类的配方按 **Lv1 / Lv5 / Lv9** 三档解锁（官方口径），解锁等级不随物品等级线性变化。
- **Tier**：成品所属的材料阶级（T1–T5）。药水按种子阶级（Tiny → Greater ≈ T1 → T5）归类。
- **配方变体**：同一成品的多种等价配方（例如不同宝石的同一件首饰、可互相替代的药水材料）已合并为一条，展开后列出全部。
- **资料未提供**：官方帮助未标注该成品的属性或材料时显示为「资料未提供」，不代表该成品没有属性。
- **覆盖范围**：当前收录 **T1–T5**；T6（Valentaal / Ash / Bamboo / Travertine / Northern Pike 等）的详细配方官方尚未提供，待补充。

## 1.0 官方配方规模【1.0 官方 Wiki】

官方 1.0 Wiki 各制作专业页共 **1418** 条配方（EA 为 1216 条），按专业：Leatherworking 193、Weaponsmithing 187、Tailoring 157、Armorsmithing 151、Jeweling 151、Hunter 139、Alchemy 136、Cooking 132、Cartography 93、Carpentry 49、Stonemasonry 30。1.0 新增 Bamboo 阶梯、背包类、箭袋、拳刃、法书（改由 Cartography）等；移除了 Toolsmithing（并入 Weaponsmithing）与 Goblin Leather / Compound bow 等。
