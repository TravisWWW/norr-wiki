## 装备 Equipment【1.0 官方 Wiki】

**Equipment** 页显示当前装备的**护甲 / 武器 / 珠宝 / 采集工具**；悬停或点击查看属性，可 **Link to chat** 分享。**Skills** 按钮进入属性与技能页，**Cosmetics** 进入已解锁外观；蓝色 **Overview** 按钮打开详细角色总览（伤害、击杀、死亡、旅行里程等）。

## 装备槽位

- 槽位：`weapon`、`shield`、`armor`、`leggings`、`boots`、`helmet`、`gloves`、`belt`、`necklace`、`ring`、`earrings`、`pet`，以及工具槽 `fishing_rod` / `farmer_hoe` / `mining_pick` / `chopping_axe`。
- **Tome 占 `shield` 槽**。部分 Tome 带 **`Bonus Strikes: N`**（每回合多打一段）。
- **职业限制生效**：`Class: Berserker,Zealot` 能穿，`Class: Ranger` / `Class: Druid` 等不能。
- 换装会把被替换的装备退回背包，**不会丢**。

## 可 roll 词条【1.0 官方 Wiki】

- **武器通用**：Physical / Spell Damage、Hit Rating、六元素伤害（Lightning / Fire / Poison / Cold / Light / Dark / Arcane）、Magic / Gold Find、Max Durability、Life / Mana Steal、Critical Strike / Critical Chance。
- **按武器类型追加**：斧 → Bleed；匕首 → Attack Speed + Bleed；矛 → Armor Pen + Bleed；剑 → Attack Speed；钝器 → Blunt；弓 → Attack Speed；弩 → Armor Pen + Bleed；法杖 → Armor Pen + Crit Chance；魔杖 → Armor Pen + Crit Strike；拳 → Counter Strike + Attack Speed；Cestus → Blunt + Thorn。
- **首饰（戒指 / 耳环 / 项链）**：范围最广，含各类抗性、Mana、Max Life、Attack Speed、Armor Pen、Life / Mana Steal、Regen、Resilience、Fortitude、Evasion 等。
- **护甲（胸 / 头 / 腿 / 手 / 腰带 / 脚）**：Defense、七种抗性、Mana、Max Life、Regen、Magic / Gold Find、Fortitude、Resilience、Evasion。
- **盾**：Defense、Block Rating、抗性、Mana、Max Life、Magic / Gold Find、Max Durability、Regen、Resilience、Fortitude。

## 品质与稀有度【1.0 官方 Wiki】

- **Quality（品质）**：在 Item Specialist 处 **Refine** 提升，**最高 100**；**Quality 16 起有几率碎装备**（建议带 Safety Charm）。各稀有度上限：

| Rarity | Min Quality | Max Quality |
|---|---|---|
| Normal | 1 | 30 |
| Magic | 1 | 35 |
| Rare | 5 | 40 |
| Epic | 10 | 45 |
| Mystical | 15 | 50 |
| Ascended | 20 | 60 |
| Legendary | 25 | 80 |
| Relic | 30 | 100 |
| Unique | 按 Tier | T1=40 / T3=50 / T5=80 / T6=100（可精炼，但不可升稀有度） |

- **Rarity（稀有度）**：决定词条数量。顺序：`Magic → Rare → Epic → Mystical → Ascended → Legendary → Relic`（+ Unique）。
- 相关道具：**Lucky Charm**（每次 +10% 镶嵌成功率，最多 5 个/次 = 100%）、**Safety Charm**（保装备不碎）、**Reroll Dice**（重 roll 词条）、**Legendary / Relic Upgrade Token**。
