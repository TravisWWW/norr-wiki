## 背包 Inventory【1.0 官方 Wiki】

- 背包即角色的随身背包；窗口标题显示**已用 / 总格数**；满了需先腾出空间才能继续收集。
- **查找物品**：悬停查看 tooltip；底部搜索框输入**至少 2 个字符**会高亮匹配物品并淡化其余。
- **移动物品**：拖拽移动 / 交换 / 堆叠；**双击**通常执行最合适的操作（装备已鉴定装备、鉴定未知装备、使用消耗品 / 材料）。银行打开时，双击可在背包与银行间移动物品。
- **物品菜单**：右键（或移动端点按）打开操作菜单：Identify / Equip / Use / Use All / Deposit / Details / Salvage / Return / Lock / Unlock / Delete 等。部分操作有场景限制（如 Deposit 需打开银行，Salvage 不能在战斗 / PvP / 远征中使用）。
- **货币袋（Currency Pouch）**：金币旁的袋子图标，集中查看特殊货币与代币；Infusions / Achievement Market / Laurel Market 等快捷入口各自独立，不占背包格。
- **Merge**：合并拆分堆叠，整理背包。部分批量操作有短冷却。
- **额外格位**：背包装备与部分宠物可通过 **+ Slots** 属性增加格位。

## 战利品背包 Loot Bag【1.0 官方 Wiki】

- 战斗掉落的物品会先进**战利品背包（Loot Bag）**，抓取你需要 / 想要的一切。
- **某些操作可能会清空战利品背包**，因此**不建议**把它当作额外储藏空间；有价值的物品请及时转入背包 / 银行。

## 钥匙 Keys【1.0 官方 Wiki】

钥匙是用于打开 **Strongbox** 与 **Dungeon Lootbox** 的消耗品。来源：**战斗掉落**（主要来自带星怪）、**Order & Bounty Boards**、**Achievement Market**、**Dock Merchant**、**Event Merchant**、**Celestial Market**。

| 钥匙 | Tier | 等级范围 |
|---|---|---|
| Copper Key | Tier 1 | 1-9 |
| Iron Key | Tier 2 | 10-19 |
| Bronze Key | Tier 3 | 20-29 |
| Steel Key | Tier 4 | 30-39 |
| Mithril Key | Tier 5 | 40-49 |

> **注意**：钥匙**只在普通世界地图（Overworld）掉落**，**不会**在地下城、远征或其它特殊事件等**实例内容**中掉落。
