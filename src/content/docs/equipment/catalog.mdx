按 **职业限制 / 装备大类 / 类型 / Tier / 物品等级** 筛选，或在搜索框输入**装备名或词条**。点击任意一行展开**完整属性与获得方式**（由哪个专业制作、需要哪些材料）。

> 本页收录的是**可制作装备**（武器 / 护甲 / 首饰 / 工具）。已收录**部分可制作装备的商店来源**；
> 纯商店、掉落与任务装备尚未系统收录。制作配方与材料反查见[制作配方图鉴](/norr-wiki/professions/crafting-catalog/)。

## 字段说明

- **物品等级（Lv）**：装备自身的需求等级。
- **职业限制**拆成两个独立维度：**护甲类型**（`Light` / `Medium` / `Heavy`，按重量限制穿戴者）与**可用职业**（如 `Archmage` / `Zealot`，多职业为数组）。工具栏里这两项分别筛选，互不混用。
- **基础属性**：该档位的基础词条；实际成品还会随品质（Quality）与稀有度浮动。
- **来源**：展开详情可见 **制作**（专业 + 各材料数量、替代配方）、**商店**（已记录的商人售价）与**该配方在配方图鉴中的直达链接**；**掉落 / 任务**来源尚未系统收录。
- **搜索**：支持按**装备名、词条、材料名**检索（输入材料名可反查用到它的装备）。
