## 珠宝分组【1.0 官方 Wiki】

制作宝石时可选择一个**分组**，在宝石自身加成（元素伤害 / 抗性）之外追加一组固定属性；**宝石分组必须与物品类型匹配**才能镶嵌。

| 分组 | 类型 | 追加属性 |
|---|---|---|
| **Power** | 进攻 | Physical / Magic / Blunt / Bleed / Elemental Damage |
| **Precision** | 进攻 | Attack Speed / Hit Rating / Critical Chance / Critical Strike / Elemental Damage |
| **Siphon** | 进攻 | Armor Penetration / Life Steal / Mana Steal / Life Regeneration / Elemental Damage |
| **Bulwark** | 防御 | Defense / Life / Fortitude / Resilience / Elemental Resistance |
| **Aegis** | 防御 | Mana / Evasion / Block Rating / Thorn Damage / Elemental Resistance |
| **Fortune** | 功能 | Maximum Durability / Mana Regeneration / Magic Find / Gold Find / Elemental Resistance |

### 分组与物品类型匹配

| 物品类型 | 进攻 | 防御 | 功能 |
|---|---|---|---|
| 武器 | ✔ | ✘ | ✘ |
| 护甲 | ✘ | ✔ | ✔ |
| 首饰 | ✔ | ✔ | ✔ |
| 宠物 | ✔ | ✔ | ✔ |

## 最大稀有度【1.0 官方 Wiki】

宝石的最大稀有度取决于其 **Tier（按需求等级）** 与**获取方式**：

- **制作**：最多到 **Mystical**，且不超过该 Tier 上限。
- **掉落 / 容器**（敌人战利品、Boss 战利品、宝箱等）：最多到 **Ascended**，且不超过该 Tier 上限。
- **Unique**：总是使用该 Tier 最高可获得宝石稀有度的**最大词条数**。

| Level | 制作上限 | 掉落 / 容器上限 | 词条数（最大） |
|---|---|---|---|
| 1 | Rare | Rare | 2 |
| 10 | Epic | Epic | 3 |
| 20 | Mystical | Mystical | 4 |
| 30+ | Mystical | Ascended | 5 |

## 属性 roll【1.0 官方 Wiki】

- **普通宝石**：每条词条在该宝石等级对应**最大值**的 **50%~100%** 之间随机。
- **Unique 宝石**：每条词条**总是满值**。

## 孔位与镶嵌

**最大插槽数**：腰带 / 靴子 / 手套 / 头盔 / 护腿 = 2；胸甲 = 3；副手 / 背包 = 无；双手武器 = 3；单手武器 = 2；戒指 / 项链 / 耳环 = 1。

**相关道具**：**Lucky Charm**（每次 +10% 镶嵌成功率，最多 5 个/次 = 100%）、**Safety Charm**（保装备不碎）、**Jewel Extractor**（提取宝石，见[物品专家](/norr-wiki/equipment/item-specialist/)）。
