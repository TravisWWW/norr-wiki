## 一件装备的处理顺序

1. 从[装备图鉴](/norr-wiki/equipment/catalog/)核对类型、等级与材料。图鉴为已收录清单，不等于全掉落数据库。
2. 阅读[鉴定与装备](/norr-wiki/equipment/identify/)，揭示隐藏词条并核对职业限制。
3. 按[装备养成攻略](/norr-wiki/guides/equipment-progression/)比较更换收益和预算。
4. 再查看[物品专家](/norr-wiki/equipment/item-specialist/)和[宝石镶嵌](/norr-wiki/equipment/jewels/)。

药水、容器与背包规则见[物品与容器](/norr-wiki/equipment/items/)；商人价格归入[经济与交易](/norr-wiki/economy/)。
