## 与 EA 版的差异（1.0 官方口径）

- 官方 1.0 共 **132** 种敌人；EA 版为 **141** 种。
- **新增 16 种**：Cute Bunny、Derro Miner / Pitwarden / Stalker、Girtablilu、Grell、Mountain Giant、Mummy、Roc、Sand Golem、Sandworm、Seafallen Oracle / Reaver / Stalker、Stone Dragon、Terramancer。
- **移除 25 种**：Cockatrice、Drow、Forest Guardian、Ghost Pirate、Goblin Engineer / Pyro / Soldier、Knight、Light Elemental、Lizardman、Miner、Mutated Lizardman、Nomadic Cleric、Peasant、Phantom Miner、Phoenix、Purifier、Skeleton Archer / Mage / Warrior、Sphinx、Troglodyte、Valkyrie、Wraith、Zombie Pirate。
- 另有 **30** 种等级区间发生变化。

## 精英前缀与 Boss

- **精英前缀（Elite Prefixes）**：部分敌人带前缀，附加额外属性，见官方页 `/p/174`。
- **Boss 清单**：见官方页 `/p/56`，或本站[副本与 Boss](/norr-wiki/quests/dungeons/)。
