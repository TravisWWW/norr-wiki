> **资料状态**：本页为 **1.0 官方公告口径**（官方 Discord），**尚未在 1.0 正式服实测**。
> EA（Legacy v0.8.x）内容见[游戏介绍与入门](/norr-wiki/getting-started/intro/)，机制差异见[1.0 机制变更](/norr-wiki/release/v1-changes/)。

## 结论速览

- **Norroth 1.0 正式版于 2026-10-16 发售**，开服时间 **13:00 CET**（官方原文）。
  - **时区换算**：10 月欧洲为夏令时 **CEST（UTC+2）**，对应 **11:00 UTC / 北京时间 19:00**。
  - 官方原文写 CET，但按 SteamDB 记录的发布时间 **2026-10-16 11:00 UTC** 换算为 **13:00 CEST**；两者一致，仅命名不同，**请以 19:00（北京时间）为准**。
- 1.0 是**全新引擎 / 服务器 / 数据库**，与旧环境**不兼容**，因此**独立开新服**；旧服保留为 **Legacy Server**。
- **两个服务器账号不互通**；跨平台（浏览器 / 手机 / 平板 / Steam / Steam Deck / 桌面）**同一账号**。
- 旧玩家按 **Legacy 奖励码**领取补偿（按 Legacy **AP + 充值额**计算）。
- **不计划在 1.0 上线后删档**。

## 2. 双服务器架构【官方】

- 1.0 基于**全新引擎 / 服务器架构 / 数据库**，与旧环境**不兼容**，因此必须**独立开新服**。
- **两个服务器账号不互通**：旧服登录在新服无效，反之亦然。
- 旧服保留为 **Legacy Server**，角色与进度继续可玩；官网提供 **`Switch to Legacy`** 按钮切换。
- **不计划在 1.0 上线后删档**（目标长期稳定运营）。
- 新服务器 / 数据库可承载**约 12 倍**于旧服的在线人数。

## 3. 账号系统【官方】

- **跨平台同一账号**：浏览器、手机、平板、Steam、Steam Deck、桌面端共用同一游戏账号，进度不丢。
- 注册方式：**普通邮箱** 或 **绑定 Steam**；1.0 另提供 **Steam 登录** 与 **Google 登录**。
- 可先用邮箱注册，之后再绑定 Steam / 改用 Gmail。
- **同一账号同一时间只能在一台设备在线**。
- **用户名保护**：新服开放时不必抢注旧名——**Legacy 奖励码即身份凭证**，官方据码核对旧账号用户名并确保归位；奖励码也相当于一次**免费改名机会**。

## 4. Legacy 奖励码（回归玩家补偿）【官方】

**计算依据**：早期口径为总游玩时长；**2025-12-18 起改为**「Legacy 服务器累计的 **Achievement Points（AP）** + 购买的 **Norroth Coins** 总额」。

**生成与截止**

- **2026-10-11：所有 Legacy 奖励码已生成**。
- 同一时间起，**1.0 Legacy 成就奖励进度正式关闭**——此后获得的成就不再计入 1.0 奖励。

**查询 / 领取**

1. **查询**：访问 `https://legacy.norroth.com` → **Settings** → **1.0 Rewards** → 显示个人奖励码。
2. **领取**：登录 1.0 服务器 → 打开 **Celestial Market** → 滚到 **v1.0 Rewards** → 输入奖励码。

**奖励内容**（视账号历史而定，可能包含）

- 专属外观（无法在别处获得）、Noble 身份、Character Soul Stone、经验符、金币符、采集加成、等级加速、Strongbox、钥匙等进度向道具。
- 奖励界面自 **2026-08-31** 起可在游戏内查看（**Menu（左上）→ 1.0 Rewards**），**每类 5 个档位**。

**注意事项**

- **每个账号只能兑换一个 Legacy 奖励码**。
- 奖励码**务必保密保存**；**丢失 / 泄露 / 误操作不补发**。

## 5. Steam 相关【官方】

- **成就**：Norroth 共约 **547** 个成就；Steam 对新 / 小游戏有上限，**初期只能加 100 个**，达到 Valve 信任 / 活跃门槛后再解锁其余。
- **定价**：Steam 渠道有 **30% 加价**，但官方**各平台售价保持一致**。
- **Noble 订阅重做**：新增 **Gold Noble / Diamond Noble**（档位、权益与待核实项见[订阅与付费服务](/norr-wiki/systems/subscription/)）。
- **Steam 客户端**：独立登录按钮、支付 API、成就同步（`steam_synced`）、独立 `Clear Cache`、分辨率 / 窗口 / 全屏设置。
- 官方呼吁：加愿望单 / 关注 / 游玩 / 评价 / 分享，以解锁更多成就位。
