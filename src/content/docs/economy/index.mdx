## 市场与货币【1.0 官方 Wiki】

- **Trading Post**：分 **Equipment** 与 **Materials** 两个板块；挂单 / 买单手续费 **2.5%**，当买 / 卖价超过商店价 10 倍时手续费 **10%**；界面给出材料价格标签辅助判断。
- **Buy Order**：设定数量与价格挂买单，金币会被**冻结**直到卖家成交或你取消。
- **Laurel Market**：用 Golden Laurels 兑换，成就 Tier 越高解锁越多。
- **Celestial Market**：高级市场，购买 Norroth Coins 与 QoL 物品、皮肤、光环等，含 Value Packs。
- **Split Stack**：右键数量 >1 的材料堆 → Split Stack → 选择数量 → Split，把一堆拆成两堆。
