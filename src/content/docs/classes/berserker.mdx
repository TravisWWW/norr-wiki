## 定位

Berserker 是近战物理输出，以双手武器（斧 / 剑 / 锤）为主，靠流血（Bleed）与高武器伤害见长；需要一定 Toughness 保证近身生存。

## 主要武器与属性倾向

| 项 | 内容 |
|---|---|
| 主要武器 | 斧 Axes / 剑 Swords / 锤 Maces（多为双手） |
| 属性倾向 | Power（伤害 / 暴击）为主，Toughness（减伤）保证生存 |
| 特色机制 | 流血、Enchanted / Sinister 阵营互斥 |
| 专属制作技能 | Cooking 烹饪 / Hunting 狩猎 / Leatherworking 制皮 / Weaponsmithing 铸武 / Stonemasonry 石工 |

## 属性成长【1.0 官方 Wiki】

| 属性 | 初始 | 每级 |
|---|---|---|
| Power | 17 | +1.2 |
| Agility | 9 | +0.6 |

| Spirit | 5 | +1.35 |

## 1.0 技能变化（相对 EA）

| 项 | EA | 1.0 |
|---|---|---|
| 技能总数 | 30 | 30 |
| 分组 | 三系精通 + Misc | 三系精通 + **Offense** + **Rage** + **Defense** |
| 新增 | — | `seismic_leap`、`primal_rage`、`ancestral_fury`、`blood_rage` |
| 移除 | — | `ancestral_assistance`、`war_god_shout`、`ancestral_seismic_leap`、`natural_resistance` |

- **新增 Rage（怒气）机制组**：`primal_rage` 是**自我减益换爆发**（格挡几率 −100%、基础防御 −2%，换攻速 / 命中 / 暴击伤害），把"高风险高输出"写进机制。
- `ancestral_seismic_leap`（EA）→ `seismic_leap`（1.0）：同思路的位移 + 眩晕技能重做，移入 Offense 组。
- `blood_rage` 归入 **Defense 组**，生命偷取成为**续航核心**（与官方 dev-blog "Blood Rage +4%、Life Steal 公式 ÷5" 一致）。
- **移除 `war_god_shout`（团队增益）与 `ancestral_assistance`（被动增伤）**：团队辅助被削弱，整体转向自我强化。
