> 近战高爆发，靠双手武器与流血打出高额伤害。

## 定位

Berserker 是近战物理输出，以双手武器（斧 / 剑 / 锤）为主，靠流血（Bleed）与高武器伤害见长；需要一定 Toughness 保证近身生存。

## 主要武器与属性倾向

| 项 | 内容 |
|---|---|
| 主要武器 | 斧 Axes / 剑 Swords / 锤 Maces（多为双手） |
| 属性倾向 | Power（伤害 / 暴击）为主，Toughness（减伤）保证生存 |
| 特色机制 | 流血、Enchanted / Sinister 阵营互斥 |
| 专属制作技能 | Cooking 烹饪 / Hunting 狩猎 / Leatherworking 制皮 / Weaponsmithing 铸武 / Stonemasonry 石工 |

## 属性成长【1.0 官方 Wiki】

| 属性 | 初始 | 每级 |
|---|---|---|
| Power | 17 | +1.2 |
| Agility | 9 | +0.6 |
| Dexterity | 13 | +0.8 |
| Spirit | 5 | +1.35 |
| Toughness | 8 | +0.5 |
| Intellect | 2 | +0.2 |
| Wisdom | 5 | +0.25 |
| Luck | 1 | +0.1 |

> 除每级自动获得的属性外，你还可**自由分配 5 点属性点**。

技能分组（1.0 官方 Wiki）：Sword Mastery、Axe Mastery、Mace Mastery、Offense、Defense、Rage。
