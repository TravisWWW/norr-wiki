## 定位

Zealot 是近战与法术混合职业，可用剑 / 锤与盾，兼具物理与光 / 暗法术；**光明与黑暗两系互斥**，同一角色只能选一边。

## 主要武器与属性倾向

| 项 | 内容 |
|---|---|
| 主要武器 | 剑 Swords / 锤 Maces + 盾 Shield |
| 属性倾向 | Power（伤害）→ Spirit（血蓝）→ Toughness（减伤） |
| 特色机制 | 光明 / 黑暗阵营互斥、盾系技能（Smite / Shield Bash / Phalanx） |
| 专属制作技能 | Armorsmithing 铸甲 / Cartography 制图 / Cooking 烹饪 / Hunting 狩猎 / Jeweling 珠宝 |

## 属性成长【1.0 官方 Wiki】

| 属性 | 初始 | 每级 |
|---|---|---|
| Power | 8 | +0.6 |

## 1.0 技能变化（相对 EA）—— 扩充最多

| 项 | EA | 1.0 |
|---|---|---|
| 技能总数 | 29 | 33 |
| 分组 | Weapon Mastery + 光 / 暗 + Misc | **Sword / Hammer Mastery（拆分）** + **Shield Mastery** + 光 / 暗 + **Spirit** + **Zeal** |
| 新增 | — | `hammer_of_justice`、`hammer_of_doom`、`iron_reckoning`、`down_to_earth`、`parry_stance`、`faithbreaker`、`divine_wrath`（共 7） |
| 移除 | — | `light_aura`、`holy_light_bubble`、`spirit_breaker` |

- **盾系（Shield Mastery）独立成组**：`shield_mastery / shield_throw / phalanx / shield_bash` 从杂项升格为独立武器线，**盾战（坦克）成为独立流派**。
- **锤系（Hammer Mastery）大幅补全**：新增光 / 暗双系锤击与增伤、AoE 眩晕，锤从"单一武器"变成**完整武器线**。
- **新增 Zeal（狂热）组**：`faithbreaker`（命中 −100 / 攻速 −50 / 暴击伤害 −50 的强力减益）等，代表**光暗均衡 / 爆发**流派。
- **新增 Spirit 组**：法力、命中、生命、寻宝，补齐续航与收益。
- **移除 `light_aura` / `holy_light_bubble`（光系防御增益）与 `spirit_breaker`（暗系减益）**：光暗系进一步**偏向输出**，防御职能交给独立的盾系。
