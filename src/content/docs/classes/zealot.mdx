## 定位

Zealot 是近战与法术混合职业，可用剑 / 锤与盾，兼具物理与光 / 暗法术；**光明与黑暗两系互斥**，同一角色只能选一边。

## 主要武器与属性倾向

| 项 | 内容 |
|---|---|
| 主要武器 | 剑 Swords / 锤 Maces + 盾 Shield |
| 属性倾向 | Power（伤害）→ Spirit（血蓝）→ Toughness（减伤） |
| 特色机制 | 光明 / 黑暗阵营互斥、盾系技能（Smite / Shield Bash / Phalanx） |
| 专属制作技能 | Armorsmithing 铸甲 / Cartography 制图 / Cooking 烹饪 / Hunting 狩猎 / Jeweling 珠宝 |

## 属性成长【1.0 官方 Wiki】

| 属性 | 初始 | 每级 |
|---|---|---|
| Power | 8 | +0.6 |
| Agility | 1 | +0.2 |
| Dexterity | 8 | +0.6 |
| Spirit | 7 | +1.45 |
| Toughness | 17 | +1.2 |
| Intellect | 13 | +0.7 |
| Wisdom | 6 | +0.25 |
| Luck | 0 | +0 |

> 除每级自动获得的属性外，你还可**自由分配 5 点属性点**。

技能分组（1.0 官方 Wiki）：Sword Mastery（剑术精通）、Hammer Mastery（锤击精通）、Shield Mastery（盾牌精通）、Light Mastery（光明精通）、Dark Mastery（黑暗精通）、Spirit（精神）、Zeal（狂热）。
