> 远程弓弩输出，辅以匕首。

## 定位

Ranger 是远程物理输出，以弓 / 弩为主、匕首为辅；命中（Dexterity）与闪避 / 攻速（Agility）是核心。

## 主要武器与属性倾向

| 项 | 内容 |
|---|---|
| 主要武器 | 弓 Bow / 弩 Crossbow / 匕首 Daggers |
| 属性倾向 | Dexterity（命中 / 暴击）+ Agility（闪避 / 攻速） |
| 特色机制 | 远程射击、流血 / 中毒状态、定身（Root）控制 |
| 专属制作技能 | Cartography 制图 / Cooking 烹饪 / Hunting 狩猎 / Leatherworking 制皮 / Carpentry 木工 |
