> 自然法术与变形，唯一能孵蛋带宠的职业。

## 定位

Druid 兼具自然系法术与变形，输出与生存较均衡；是**唯一能孵化宠物蛋并携带宠物**的职业，也可替其他玩家孵蛋。

## 主要武器与属性倾向

| 项 | 内容 |
|---|---|
| 主要武器 | 法杖 Staff（双手）/ 单手 + 盾 / 副手 |
| 属性倾向 | Spirit（血蓝）与 Power（法伤）兼顾 |
| 特色机制 | 变形、自然法术、宠物（Petbreeding） |
| 专属制作技能 | Cooking 烹饪 / Hunting 狩猎 / Leatherworking 制皮 / Petbreeding 养宠 / Tailoring 裁缝 |
