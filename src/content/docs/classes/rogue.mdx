> 潜行、毒与双持的敏捷近战。

## 定位

Rogue 是敏捷型近战 / 远程混合，擅长潜行、毒与双持，武器选择多样（匕首 / 拳刃 / 投掷）。

## 主要武器与属性倾向

| 项 | 内容 |
|---|---|
| 主要武器 | 匕首 Daggers / 拳刃 Katars / 投掷武器 Throwing |
| 属性倾向 | Dexterity（命中 / 暴击）+ Agility（闪避 / 攻速） |
| 特色机制 | 潜行、中毒（Poison）、Radiant / Shadow 阵营互斥 |
| 专属制作技能 | Toolsmithing 工具 / Cartography 制图 / Cooking 烹饪 / Hunting 狩猎 / Leatherworking 制皮 |

## 属性成长【1.0 官方 Wiki】

| 属性 | 初始 | 每级 |
|---|---|---|
| Power | 9 | +0.5 |
| Agility | 17 | +1.2 |
| Dexterity | 13 | +0.8 |
| Spirit | 5 | +1.2 |
| Toughness | 3 | +0.2 |
| Intellect | 3 | +0.3 |
| Wisdom | 5 | +0.3 |
| Luck | 5 | +0.5 |

> 除每级自动获得的属性外，你还可**自由分配 5 点属性点**。

技能分组（1.0 官方 Wiki）：Dagger Mastery、Throwing Mastery、Fists Mastery、Mobility、Trickery、Sabotage。
