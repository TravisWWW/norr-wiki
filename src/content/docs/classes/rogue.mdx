> 潜行、毒与双持的敏捷近战。

## 定位

Rogue 是敏捷型近战 / 远程混合，擅长潜行、毒与双持，武器选择多样（匕首 / 拳刃 / 投掷）。

## 主要武器与属性倾向

| 项 | 内容 |
|---|---|
| 主要武器 | 匕首 Daggers / 拳刃 Katars / 投掷武器 Throwing |
| 属性倾向 | Dexterity（命中 / 暴击）+ Agility（闪避 / 攻速） |
| 特色机制 | 潜行、中毒（Poison）、Radiant / Shadow 阵营互斥 |
| 专属制作技能 | Toolsmithing 工具 / Cartography 制图 / Cooking 烹饪 / Hunting 狩猎 / Leatherworking 制皮 |
