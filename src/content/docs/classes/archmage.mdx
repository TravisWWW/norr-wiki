## 定位

Archmage 是纯远程法术职业，伤害来自元素法术与法杖 / 魔杖；生存依赖魔法盾与法力续航，属于偏脆但爆发高的定位。四系元素（Arcane 奥术 / Fire 火 / Ice 冰 / Lightning 雷）各有对应的精通被动与主动法术。

## 主要武器与属性倾向

| 项 | 内容 |
|---|---|
| 主要武器 | 法杖 Staff（双手）/ 魔杖 Wand（单手）+ 副手（法书 Tome / 盾） |
| 属性倾向 | Power（法伤 / 暴击）为主，Spirit（血蓝）续航；命中不足再补 Dexterity |
| 特色机制 | 元素法术、魔法盾、法力消耗 |
| 专属制作技能 | Alchemy 炼金 / Cartography 制图 / Cooking 烹饪 / Jeweling 珠宝 / Tailoring 裁缝 |

## 1.0 技能变化（相对 EA）

| 项 | EA | 1.0 |
|---|---|---|
| 技能总数 | 27 | 26 |
| 分组 | 三系精通 + Misc | 三系精通 + **Mana** + **Offensive**（Misc 仅剩 Magic Orb / Treasure Finder） |
| 新增 | — | `lightning_thrust`（闪电穿刺，Lv.5） |
| 移除 | — | `lightning_attack`、`mana_armor` |

- **三系对称化**：奥术 / 闪电 / 火焰现在都是 `精通 → 弹 → 穿刺 → 风暴 → 衰弱 → 光束` 六级结构，`lightning_thrust` 补齐闪电系缺失的穿刺位。
- **失去 `mana_armor`**（EA：+70 基础防御 / +50 基础抗性 / +30 坚韧 / −25 法力）：法师不再有"法力换防御"的生存手段，生存转向 `glass_cannon` / `mana_shield` 取舍。
- **Mana 独立成组**：`mana_pool / mana_recovery / mana_shield` 从杂项升格为显式流派。
