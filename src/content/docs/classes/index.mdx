Norroth 有 **6 个职业**，每个职业有独立的技能树与专属生活技能。用 [技能天赋模拟器](/norr-wiki/tools/talent/) 可以自由加点预览。

| 职业 | 定位 | 专属生活技能 |
|---|---|---|
| <img class="nr-ci" src="/norr-wiki/img/classes/archmage.gif" alt="" /> [Archmage 法师](/norr-wiki/classes/archmage/) | 远程法术输出 | Alchemy · Cartography · Cooking · Jeweling · Tailoring |
| <img class="nr-ci" src="/norr-wiki/img/classes/berserker.gif" alt="" /> [Berserker 狂战士](/norr-wiki/classes/berserker/) | 近战高爆发 | Cooking · Hunting · Leatherworking · Weaponsmithing · Stonemasonry |
| <img class="nr-ci" src="/norr-wiki/img/classes/druid.gif" alt="" /> [Druid 德鲁伊](/norr-wiki/classes/druid/) | 自然法术 / 变形（唯一可孵蛋带宠） | Cooking · Hunting · Leatherworking · Petbreeding · Tailoring |
| <img class="nr-ci" src="/norr-wiki/img/classes/ranger.gif" alt="" /> [Ranger 游侠](/norr-wiki/classes/ranger/) | 远程弓弩 | Cartography · Cooking · Hunting · Leatherworking · Carpentry |
| <img class="nr-ci" src="/norr-wiki/img/classes/rogue.gif" alt="" /> [Rogue 盗贼](/norr-wiki/classes/rogue/) | 潜行 / 毒 / 双持 | Toolsmithing · Cartography · Cooking · Hunting · Leatherworking |
| <img class="nr-ci" src="/norr-wiki/img/classes/zealot.gif" alt="" /> [Zealot 狂热者](/norr-wiki/classes/zealot/) | 近战 + 法术（光暗互斥） | Armorsmithing · Cartography · Cooking · Hunting · Jeweling |

> 每个职业都能练 **7 个采集**（Chopping / Farming / Fishing / Foraging / Mining / Quarrying / Scavenging）；上表只列**职业专属**的制作技能。
