## 定位（据技能数据推断）

Plaguebringer 是**法术输出 / 持续伤害型职业**：

- **法术线**：**瘟疫（中毒 Poison）**与**暗影（Dark）**两系对称魔法（`hex_of_rot` / `hex_of_despair`、`wither` / `shadow_mist`、`toxic_rain` / `call_of_shadows` 等）。
- **药剂线（Tonic Mastery）**：`weakening_tonic`、`supressing_tonic`、`nightmare_tonic`、`alleviation_tonic`、`resistance_tonic` 提供减益、沉默、恐惧、治疗与抗性。
- **虹吸线（Siphon）**：`siphon_mana`、`siphon_health`、`siphon_strength` 吸取法力 / 生命 / 削弱敌人。
- **腐蚀（Corruption）**：`corruption_mastery`、`bloodbriar_pact`（荆棘 + 生命偷取）。
