## 快速检查

- 确认其它网站能正常访问（排除网络问题）。
- 刷新页面（**CTRL+F5**）或重启客户端。
- 换一个浏览器（Chrome / Firefox / Edge）。
- 临时**关闭 VPN / 代理**，它们可能拦截游戏流量。
- 查看是否有维护公告（News Board / Discord）。

## 清除缓存

- 菜单里选择 **Clear Cache**，按你的设备提示操作；详见[缓存与 Cookie](/norr-wiki/support/technical/cache-cookies/)。

## 仍然不行？

- 记录**浏览器 / 客户端版本**与屏幕上的错误文本。
- 开 **Support Ticket** 或使用 **Bugs & Suggestions**。
