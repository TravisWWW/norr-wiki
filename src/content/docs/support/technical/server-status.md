Norroth 有时会因为更新与维护**主动下线或限流**。

## 如何查看

- 看游戏内 **News Board**。
- 查看官方 **Discord / 社交公告**。
- 若登录页显示维护信息，等它清除后再进。

## 维护期间

- 不要一直刷新，等**恢复通知**。
- 维护期间进行的进度与购买，恢复后可能需要几分钟才结算。

## 非计划故障

- 若大量玩家同时掉线，官方通常已在处理。
- 若**别人能进你不能**，见[无法加载](/norr-wiki/support/technical/game-not-loading/)与[断线](/norr-wiki/support/technical/connection-disconnects/)。
