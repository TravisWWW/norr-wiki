## 推荐

- 最好使用 **Chrome / Firefox / Opera / Edge**。
- 保持浏览器为**最新版本**。
- 允许 Norroth 站点使用 **JavaScript 与 Cookie**。

## 常见问题

- 过旧的浏览器或 **Internet Explorer 不受支持**。
- 扩展、脚本拦截器或企业过滤可能破坏游戏。
- **隐私 / 无痕模式**会更频繁地要求重新登录。

## 可以尝试

- 更新浏览器后**硬刷新**（CTRL+F5）或清缓存。
- 用**干净配置**或另一个无扩展浏览器。
- 手机端见[移动端](/norr-wiki/support/technical/mobile/)。
