## 联系前先确认

- 在银行 / Steam 确认两笔扣款是否都已**完成（completed）**。
- 在游戏内确认收到了**一次还是两次**金币 / 物品发放。
- **待处理 + 已完成**看起来像重复扣费，直到待处理那笔消失。

## 联系 Support

- 开 **Support Ticket** 并选择 **Payments**。
- 提供**两个交易 ID / 收据、时间、金额与角色名**。
- 在官方调查期间**不要发起 chargeback**，尽量先沟通。
