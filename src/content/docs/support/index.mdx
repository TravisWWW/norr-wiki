本栏目收录**账号、技术支持、支付与规则条款**，以及游戏背景与团队信息。内容主要来自**官方 1.0 Wiki**（2026-10-15 抓取），属于官方口径，**未在正式服逐条实测**。

| 分组 | 内容 |
|---|---|
| **账号** | 账号设置、登录与密码、邮箱验证、账号安全（2FA）、角色恢复、封禁与暂停 |
| **技术支持** | 无法加载、浏览器兼容、断线、卡顿、报错、缓存与 Cookie、移动端、Steam、桌面端、Bug 报告、服务器状态 |
| **支付** | 支付方式、支付失败、未到账、待处理、退款、错误扣费 |
| **规则与条款** | 聊天准则、通用规则、服务条款、Cookie 政策、隐私政策 |
| **关于** | 管理团队、游戏起源、推荐好友 |

> 遇到问题优先走**游戏内 Support Ticket**（玩家菜单 → Support / Bugs & Suggestions），公开频道里的报错容易被忽略。
