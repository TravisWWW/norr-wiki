从**账号与登出窗口**打开齿轮图标进入设置，可管理快捷游戏选项、进入完整设置菜单、切换角色、安全登出，以及使用 **Friends / News / Refer a Friend / Report Bug / Unstuck** 等快捷方式。

## 快捷开关

| 开关 | 作用 |
|---|---|
| **Auto Combat** | 按 Settings → Controls 中的规则自动战斗（如自动喝药、尝试逃跑） |
| **Auto Loot** | 战斗后自动拾取可用战利品 |
| **Auto Scavenge** | 击杀动物后自动拾取 Remains，无需逐个点击 |

> 自动战斗的详细规则见[战斗机制](/norr-wiki/combat/mechanics/)与[技能系统](/norr-wiki/combat/skills/)。
