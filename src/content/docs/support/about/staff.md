## 职位

| 职位 | 职责 |
|---|---|
| **Developer** | Norroth 的**独立开发者与所有者** |
| **General Manager** | 提供 IT 支持、项目管理，统筹全体 Staff 的运作（领导、协调与绩效） |
| **Content Manager** | 通过社交媒体与通讯发布消息，添加任务并协助剧情 |
| **Senior Community Manager** | 统筹 Community Manager 与 Moderator 的工作，确保运作顺畅与准则执行 |
| **Community Manager** | 回答社区问题，引导玩家到正确渠道上报 Bug 与建议 |
| **Staff Trainee** | 通过支持社区、协助玩家来积累经验的实习生 |
| **Chat Moderator** | 维护聊天频道积极、尊重与友好的氛围 |
| **You** | 可爱的玩家 &lt;3 感谢参与 Norroth |
