## Activities 面板【1.0 官方 Wiki】

**Activities** 是循环内容的入口：每日任务、世界事件、挑战、社交工具与进度追踪。从 HUD 的 **Activities 图标**打开；条目随等级解锁，未解锁项显示所需等级。

| 条目 | 解锁 | 内容 |
|---|---|---|
| **Dailies** | Lv2 | 每天最多 12 条；每 3 条给一个额外袋；00:00 服务器时间重置 |
| **Codices** | Lv2 | 追踪 Bestiary / Artifacts / Augments 收藏并领奖（账号共享，分 Softcore / Hardcore） |
| **Event Gate** | Lv3 | 捐赠 Fragments 开门，参加约 20 分钟的限时世界事件 |
| **Leaderboards** | Lv4 | 按战斗 / 制作等分类排行；分 Current / Previous，赛季前 50 名有奖 |
| **Abyssal Tower** | Lv5 | 从城市进入的**单人爬塔**；Normal 起步，逐步解锁 Nightmare / Chaos |
| **Group Finder** | Lv9 | 找队伍、浏览公会、加入公开远征 |
| **Battle Arena** | Lv10 | 从城市进入；每场 1 个 Battle Token；按等级分区 |
| **Personal Estate** | Lv10 | 购买个人庄园，解锁 / 升级设施 |
| **Overlord Chamber** | Lv30 | 世界 Boss，固定时间刷新（01:00 / 10:00 / 19:00 CEST） |

## 每日服务器事件【1.0 官方 Wiki】

- **按周轮换**的每日服务器事件，已知包括 **Wandering Merchant / Starlit Hunt / Hidden Hoard / Resource Rush / Hatchglow / Doubledawn / Arena Frenzy / Double XP Weekend**，详见[活动入口与限时事件](/norr-wiki/quests/events/)。
- **Void Rift Outbreak**：关闭整波裂隙后给全服 **30 分钟随机增益**。

## 召唤图腾 Summoning Totem【1.0 官方 Wiki】

- 部分地图上的**特殊地点**，消耗 **Lost Soul Shards** 召唤一只与该图相关的**额外敌人**。
- 站在图腾上打开界面，选择仪式强度后按 **Start Ritual**；成功后敌人出现在附近。
- **碎片来源**：在有图腾的地图上，**击败敌人**可获得 Lost Soul Shards；数量显示在图腾窗口与 Currency Pouch。
- **三档仪式**：**Champion 7 / Rare 11 / Elite 15** 个碎片，越贵召唤越强；召唤的敌人仍基于该图常见生物。
- **落点**：召唤敌人出现在附近空格；**若无有效落点，仪式失败并退还碎片**。
