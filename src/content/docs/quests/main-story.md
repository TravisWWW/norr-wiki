> **剧透提示**：本页包含主线任务名与剧情走向，介意剧透请谨慎阅读。
>
> 主线是一条「跑腿 + 交材料」的长链，每环奖励 25-50 金币 + 50-100 战斗经验，偶尔给 Strongbox /
> Quest Pouch / 成品食物，并且**逐步解锁新区域**（Sewers 就是主线解锁的）。

## 1. 主线怎么推进

主线**不在任务板上**，也没有 NPC 对话入口。它靠**任务链字段**串起来：

1. 接下一个主线任务；
2. 拿到目标地图 + 坐标；
3. 走到那个坐标（跨图就先用 gate / waygate）；
4. 交任务，读下一环，回到第 1 步。

支线 / 职业任务同样可以接。

## 2. 已实测的主线链

| 顺序 | 名称 | 目标 | 奖励 |
|---|---|---|---|
| 1 | Meeting The Leader | El Caspar 45/30 | 25 币 + 50 XP |
| 2 | Stashing It Away | El Caspar 20/32（Stash） | 1x Copper Strongbox + 1x Cotton Quest Pouch + 25 币 + 50 XP |
| 3 | Back to the Bearded Man | El Caspar 45/30 | 25 币 |
| 4 | The Road | El Caspar 40/28 | 1x Cotton Quest Pouch + 25 币 |
| 5 | **Meeting The Ratman** | **Sewers 42/17** | 25 币 + 50 XP |
| 6 | Talking to Ratman | El Caspar 45/30 | 25 币 |
| 7 | Go To The Cook | El Caspar 31/42（Cook） | 25 币 |
| 8 | Ratman Delicacies | 交 5x Mucky Meat + 2x Mucky Bone + 5x Mucky Vegetables | 1x Mucky Fruit Salad + 50 币 + 100 XP |
| 9 | Bait The Ratman | Sewers 42/17 | 25 币 |
| 10 | The Ratman Speaks | Sewers 42/17 | 25 币 |
| 11 | Bearded Man: Ratman | El Caspar | （后续） |

**进入 Sewers 的条件就是主线第 5 环 `Meeting The Ratman`。**

- **前置条件**：每环的**前置 = 上一环**，完成后自动接到**下一环**（表中「顺序」即链序）。
- **目标地图**：见「目标」列（坐标格式为 `地图 横/纵`）；跨图先用 gate / waygate 过去。
- **奖励**：见「奖励」列；奖励进掉落窗，需手动领取。

## 3. Sewers（下水道）

- 入口：**El Caspar 39/28** 的 gate（地图上写 `Sewers (Lv.1)`）。
- 内部：gate 回 El Caspar、`entrance` 通往更深一层、一个杂物点。
- 怪物等级 1-3，主线只是让你跑进去交任务。

## 4. 任务系统的其它口径

- **接任务**：任何地点都能接（不必站在 NPC 前）。
- **交任务**：在任务日志里点 **Finish / 完成**。
- **放弃**：cancel。
- **奖励进掉落窗**，必须领取。
- 任务日志分 **Main / Side / Daily / Order / Bounty** 五类；**同时可持有约 7 个任务**。
- **Order 任务是「材料 + Laurels」的消耗**（例：Elundi「New Clothes」要 15x scrap_leather_shoe_base + **30 Laurels**，
  只给 400 XP）——**收益较低，不建议作为主要收益来源**。
- **Bounty 任务是纯收益**（Elundi Lv10 板：Killer Insects 杀 30 → 60 Laurels + 600 XP + 5% 概率 Quest Pouch）。
  → **优先做 Bounty，Order 只在需要某个特定奖励时才做。**

## 5. Quest Pouch / Strongbox 奖励

主线与 Bounty 会给 **Cotton Quest Pouch**、**Copper Strongbox**。两者都是容器，打开后领取内容。
