## 1. 日常任务（Dailies）【官方】

> 官方原文：每天有一组任务；**每完成 3 个日常给一个额外战利品袋**，完成 **12 个**拿满所有袋子。
> 袋子含金币、Laurels、Spirit Essence，视袋子不同最多 4 个公会代币，也可能出代币/骰子/箱子/钥匙。
> **每日 00:00 服务器时间重置。**

**奖励档位（实测，按 Daily Tasks Points 30 / 60 / 90 / 120）**：

| 档 | 奖励 |
|---|---|
| 30 | 5x Laurels + 100x Coins + 100x Spirit Essence |
| 60 | 5x Laurels + 100x Coins + 100x Spirit Essence |
| 90 | 20x Laurels + 250x Coins + 250x Spirit Essence + 1x 随机 Token/Dice/Chest/Key |
| 120 | 40x Laurels + 500x Coins + 1000x Spirit Essence + 2x 随机 + 2x Battle Arena Token + 2x Ducats |

- 每条任务固定 **10 点**，档位在 **30 / 60 / 90 / 120**，可一次性领满所有已达成的档位。
- 常见任务：Kill an Enemy、Gather a Resource、Sell Resource to Vendor、Repair Item(s)、
  Accept a Board Quest、Craft a Material / Equipment、Refine Quality、Upgrade Rarity、
  Mass Salvage、Collect Scrap、Use the Wishing Well、Claim Your Daily Gift 等。
- **结论**：日常是**单位时间收益最高**的循环之一（Laurels + Spirit Essence + 代币），每天上线先清日常。

## 2. 任务板（Quest Boards）【官方】

> 官方原文：每个城镇有**三种**任务板；**所有任务板每周二 12:00 服务器时间补货**。

| 任务板 | 内容 | 奖励 |
|---|---|---|
| **Client Order Board** | 城镇居民的材料/成品订单 | 金币/材料，偶尔稀有或高级奖励。**板子 Tier = 城镇 Tier** |
| **Bounty Hunter Board** | 击杀指定敌人 N 只 | 有用道具，偶尔稀有或高级奖励 |
| **Guild Quest Board** | 大规模公会专属击杀任务 | 只能在公会领地接取、需要权限 |

**实测样例**：

- Client Order：「A Statue for the Mayor」= 交 **24 Slate** → **1 Copper Key + 200 Quarrying XP**。
- Bounty：「Savage Raiders」= 杀 **14 个人形怪** → **15 Laurels + 150 Combat XP + 5% bonus Pouch**。
- 接下的订单会出现在 journal 的 **Order / Bounty** 页，进度自动追踪。

## 3. 任务日志（Quest Journal）【官方】

> 官方原文：Journal 里能看到所有已接、未完成的任务，以及已完成任务的概览。
> 任务分 **Main Storyline（红）** 和 **Side Quests（蓝）**；世界地图上红点 = 有任务。

- 空 = 没有进行中的任务。
- 接下的订单会显示进度（例：`Slate (3/24)`）。

## 4. 接 / 交任务口径

- **接任务**：任何地点都能接，不必站在 NPC 前。
- **交任务**：用「finish」（不是 complete）。
- **放弃**：cancel。
- **奖励进掉落窗**，必须领取。
- **同时持有任务上限约 7 个**（实测接到 7 个后新的接不进来）。

## 5. 每日 / 每周节奏表

| 周期 | 事件 | 时间（服务器） |
|---|---|---|
| 每日 | Dailies 重置 | 00:00 |
| 每日 | Overlord 刷新 | 01:00 / 10:00 / 19:00 |
| 每周 | Quest Boards 补货 | 周二 12:00 |
| 每周 | Battle Arena 结算 + 邮局发奖 | 周一 00:01 |
| 每周 | Weekly Raffle 抽奖 | 周六 18:00 |
| 赛季 | Leaderboard 赛季 | 每季约 3 个月 |

## 6. 上线例行流程

1. 查看当天日常，能领的领掉。
2. 在城里接订单 / 悬赏（周二补货后优先）。
3. 检查主线 / 支线。
4. 打怪 / 采集 / 制作推进任务进度。
5. 回城交任务、卖垃圾、补药、修装备。
