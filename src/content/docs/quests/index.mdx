## 按参与方式区分

| 分区 | 用途与阅读顺序 |
|---|---|
| 任务 | [任务板与日志](/norr-wiki/quests/boards/) → [主线任务链](/norr-wiki/quests/main-story/)；按任务类型查接取和完成方式 |
| 每日安排 | [日常任务](/norr-wiki/quests/dailies/) → [日常安排攻略](/norr-wiki/guides/daily-routine/)；按当天任务池与成本取舍 |
| PvE 挑战 | [副本](/norr-wiki/quests/dungeons/) → [深渊塔](/norr-wiki/quests/abyssal-tower/) → [世界 Boss](/norr-wiki/quests/world-boss/) |
| PvP | [竞技场](/norr-wiki/quests/arena/)；死亡和经验规则与普通 PvE 分开阅读 |
| 活动与探索 | [世界事件](/norr-wiki/quests/world-events/)与[活动、远征](/norr-wiki/quests/events/)；以游戏内开放状态为准 |

具体奖励以所在服务器面板为准。副本清单提供入口资料，尚不能替代逐个 Boss 的战术攻略。
