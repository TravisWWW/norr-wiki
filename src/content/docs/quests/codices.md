**Codex（图鉴）**追踪三类收藏：**Bestiary（怪物）**、**Artifacts（神器）**、**Augments（强化）**。游玩中逐步解锁条目，打开 Codex 查看并**领取奖励**。进度**账号共享**，并分 **Softcore / Hardcore**。

## Bestiary（怪物图鉴）

- **首次在战斗遭遇**某敌人时加入图鉴。
- 条目按稀有度分组：**Normal / Bosses / Overlords**。
- 可直接从 Bestiary 领取奖励；击败已知敌人会**增加击杀数**。
- 新的击杀里程碑会解锁新奖励，记得常回来看。

## Artifacts（神器）

- 通过**采集节点**或与**村民对话**发现。
- **地图类型决定神器稀有度**（Overworld / Dungeons / Cities）。
- 找到后可在 Artifacts 图鉴中查看并领取。

## Augments（强化）

- 通过**获得或分解**与特定技能绑定的 **Unique 物品**解锁。
