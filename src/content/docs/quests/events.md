## Event Gate（Sacred Wilds）【官方】

- **激活**：玩家累计捐赠 **100 Fragments** 后开门，进入 Sacred Wilds Lobby。
- **时长 20 分钟**：可在大厅采集，或按等级进对应的门打怪（主要是 **Wyverns** 或 **Event Boss**）。
- **积分**：战斗和采集都给个人积分；**全服 20 分钟内至少 500 分**才有战利品。
- **奖励**：活动结束后通过**游戏内邮件**发放；积分决定奖励品质。Event Tickets 按 Event Points 发。

## Expeditions（探险）【官方】

远征的买船、Hull 升级、地图 Tier、奖励与海盗风险集中在[船只与航海](/norr-wiki/systems/sailing/)维护。该页同时区分 EA 远征与 1.0 已公布的航海内容。

## 限时活动一览【1.0 官方 Wiki】

| 活动 | 内容 |
|---|---|
| **Void Rift Outbreak** | 随机在 **Lv20+ 且有 Waygate 的地图**出现裂缝；关闭整波后**全服获得 30 分钟随机全局增益** |
| **Hidden Hoard** | 每次远征有 **20%** 概率发现隐藏岛 **Loot Bay**（哥布林宝藏、稀有掉落、可能隐藏独特宠物皮肤） |
| **Starlit Hunt** | 带星怪出现更频繁（野外与远征），掉落更好 |
| **Resource Rush** | 随机选定一个采集专业，采集该专业资源点有概率获得 **Resource Rush Token**，可在 Rush Merchant 兑换限时物品 |
| **Hatchglow** | 所有宠物孵化 **+100% 孵化力**，同时提升稀有度与 Growth 概率 |
| **Doubledawn** | 活动门开启期间，活动内获得的 **Event Points 翻倍** |
| **Arena Frenzy** | 竞技场胜场进度 **+100%**，晋级更快（需 Lv10） |
| **Wandering Merchant** | 神秘商人随机出现在公共区域，**每次购买后转移位置**，库存有限；不会出现在 Boss 房或副本内 |
| **Double XP Weekend** | 随机一个专业获得**双倍经验**（含采集、制作、战斗击杀）；**AFK 模式不享受** |

**Event Gate（Sacred Wilds）**：玩家累计捐赠 **100 Fragments** 后开门，进入 Sacred Wilds Lobby；活动 **20 分钟**，可按等级进门采集或战斗。
**Event Anomalies**：每次进入副本 / 远征有 **15%** 概率触发，按权重随机（Loot Goblin Invasion 稀有、Elite Ambush、Void Rift、Secret Armory 等）。
